# Novel Agents オンボーディング

このスキルは、`/novel` スキルを使うための**個人設定**を対話的に作成します。
生成された設定はプロジェクト内（`.claude/personal/SKILL.md`）に保存されます。
このファイルは `.gitignore` 済みのため各自のローカル環境のみに存在します。

## 実行フロー

### STEP 1: ヒアリング

2〜3問ずつ段階的に聞く。一度に全部聞かない。

#### 第1ラウンド: 基本情報
1. **名前**: 「どう呼ばれたいですか？」
2. **小説のタイトル（仮）**: 「執筆中の小説のタイトルを教えてください」
3. **ジャンル・雰囲気**: 「どんな雰囲気の異世界ファンタジーですか？」
   - 重厚な剣と魔法系
   - ライトで読みやすい系
   - ダークファンタジー系
   - Other（自由記述）

#### 第2ラウンド: 執筆スタイル
4. **文体の好み**: 「どんな文体で書いていますか？」（例: 三人称・主人公視点寄り、一人称、など）
5. **1章の目安文字数**: 「1章あたりの目安文字数は？」（例: 3,000〜5,000字）
6. **絶対に使いたくない表現**: 「小説に入れたくない表現・展開はありますか？」（自由記述）

#### 第3ラウンド: 作品のテーマ
7. **大切にしているテーマ**: 「この小説で大切にしているテーマ・メッセージを教えてください」
8. **既存資料の配置状況**: 「reference/ フォルダに小説や設定資料は置きましたか？」
   - 置いた → 確認してそのまま進む
   - まだ → reference/README.md を案内する

### STEP 2: 設定ファイル生成

ヒアリング結果を基に `.claude/personal/SKILL.md` を生成する。

**生成テンプレート:**

```markdown
# Novel Agents マネージャーAI（個人設定）

## 基本情報

- **呼び名**: {名前}
- **作品タイトル**: {タイトル}
- **ジャンル・雰囲気**: {ジャンル}

## 執筆スタイル設定

- **文体**: {文体の好み}
- **1章の目安文字数**: {文字数}
- **視点**: {一人称 / 三人称など}

## 絶対NG

{避けたい表現・展開を箇条書きで}

## 作品のテーマ・メッセージ

{大切にしているテーマを記載}

## AIくささチェック観点

マネージャーチェックの「作者の声に聞こえるか」を判定する際、以下の観点で読む:
- 異世界ファンタジーの定型表現（「かくして」「〜なのであった」「輝かしき」）がないか
- 地の文が「設定の説明書」になっていないか
- キャラクターが「物語のために動かされている」感がないか
- 感情を「語って」いないか（Show, don't tell）
{ユーザーが追加した絶対NGがあれば、ここに具体的なチェック項目として追加}

## フロー定義

フロー定義はプロジェクト共有版を使用する:
- 小説執筆: プロジェクトの `.claude/skills/novel/references/novel-flow.md`
```

### STEP 3: 確認

生成した設定ファイルの内容をユーザーに見せて確認を取る。
修正があれば反映してから保存する。

### STEP 4: 保存 + 完了メッセージ

1. `.claude/personal/` ディレクトリを作成（なければ）
2. `.claude/personal/SKILL.md` に書き込む
3. 完了メッセージを表示:

```
セットアップ完了！

【生成ファイル】.claude/personal/SKILL.md
【効果】/novel スキル実行時に、あなたの執筆スタイル・絶対NGが自動で反映されます

次のステップ:
- reference/ フォルダに既存の小説・設定資料を配置してください（reference/README.md 参照）
- 準備ができたら `/novel 書きたい内容` で執筆開始です
- 設定を変更したい場合は `/onboarding` を再実行してください
```

## 注意事項

- 既に `.claude/personal/SKILL.md` が存在する場合は、上書きしてよいかユーザーに確認する
- ヒアリングの回答が薄い場合は、具体例を示して深掘りする
- 全項目が必須ではない。スキップされた項目はデフォルト値を使う
