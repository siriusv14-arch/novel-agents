## 1. ep10登場予定キャラクター一覧（ep9終了時点の状態）

### テル（桜井輝明 / WhiteCrow）
- **状態**: 廊下に一人、イレーネから受け取った七十三年前の原本複写を手に持ち、一行目を読んだ直後
- **内部状態**: 「黒板に触れた」という記述が意味するものを処理し始めている。前夜に「root権限で読めないものがある＝自分のroot権限よりも上の権限体系が存在する」という事実を認識した直後でもある
- **役割上の立場**: ep9でイレーネから「形式の特定はあなたが担当」と正式に役割を与えられた。下っ端の新入りながら、黒板でしか読めない領域を扱える唯一の人材として実質的な調査責任を持つ
- **口調**: イレーネには「〜です/ます」の丁寧語。推測・仮説表現が多い。一文で結論を言い切らない
- **注意点**: 前世の記憶（ランサムウェア被害・ログ欠損発見・誰にも「正しかった」と言われなかった経験）が内部回想として浮かびやすい精神状態にある

### イレーネ・ヴァルス
- **状態**: ep9でバルナバスの命令範囲を超えた独自判断でテルに記録を渡した直後。廊下を振り返らずに歩き去った
- **立場変化**: ep9は「査定から協力へ」の転換点として位置付けられる（world-settings.md §6のキャラクター関係変化表：「協力」フェーズに突入）。ただし感情的な接近は第2章まで慎重に抑制する
- **口調**: 端的で断定的。「〜ね」「〜でしょう」「〜確認する」「〜見ておく」「〜記録しておく」が多い。余計な感情表現をしない
- **今後の動き**: ep9会議で「七十三年前の記録の方は別途、私が見ておく」と宣言した。独自に調査を進める可能性がある。バルナバスへの報告ラインを迂回した行動の後始末がまだない
- **注意点**: 「前世」に踏み込む台詞は第2章以降まで書かない（world-settings.md §6）

### アルリック
- **状態**: ep9会議でノードの応答なし問題を聞き「07の前に何があったのかということだな」と低い声で言った。テルとセルダ村の男の面談の後で目を伏せた
- **役割**: ep9で「中継塔の外周は引き続き騎士団で固める」という防衛任務を再確認
- **口調**: 口数が少ない。短く断言する。テルをまだ完全に信頼していないが、能力は認め始めている
- **注意点**: 「神のシステムは不可侵」という信念はまだ揺らいでいない（揺らぐのは中〜後半章）

### バルナバス
- **状態**: ep9で副官から「七十三年前の件に別の記録形式が確認された」という報告を受け、書類をただ置き、一度目を細めた。表情を読ませなかった
- **位置**: 執務室の北側窓辺。灰色の空（冬の終わり）を背景に
- **注意点**: バルナバスは転生者の存在を把握している数少ない人物（F-06）。情報を知りながら態度を明かさないという描写を維持する。今のところ直接テルに接触する理由はないが、七十三年前の記録が動き始めたことを認識した

### セルダ村の男（名前未定義）
- **状態**: ep9でテルと面談を終え、聖務局の詰め所に拘留中。「悪いとは思っていません」という事実だけを机の上に置いた
- **ep10での役割**: 脇役として残っている。再登場するかどうかはプロットディレクターの判断に委ねる
- **注意点**: ep9でテルが「このひとは悪人じゃない」という内部認識を確立した。この認識はテルの思想的基盤として今後も持続する

### シリア（ep9不登場）

- **ep10での役割**: 登場させる場合はQY-NODE感知能力（F-04、F-10、F-19）の文脈で機能する。ただし「まだ存在を意識させる程度」の登場でも可

## 2. ep10に関係する世界設定

### 技術体系：黒板（物理コンソール）とroot権限

**確定している仕様**（ep1〜ep9より）
- 黒板は神のシステムにroot権限でアクセスできる「物理コンソール」
- これまでほぼあらゆる領域に通じていたが、ep9で初めて「アクセス権限不足」という壁にぶつかった
- `RECORD_BOUNDARY` エラー：記録境界。「無い」のではなく「読めない」を意味する
- `protocol_origin` フィールド：プロトコル継承元。NODE-07がどの古い形式を引き継いでいるかを示す系譜
- コマンド記法（ep9確認済み）：`> trace --target=NODE-07 --history=before` 形式

**ep10で扱うべき技術的謎**
- NODE-07以前の形式（別の権限体系下にある領域）にどうアクセスするか
- 七十三年前の「もう一人」が使っていた形式と現在のNODE-07の関係
- テルのroot権限よりも上位の権限体系とは何か（F-37）

### 技術体系：QY-NODEのアーキテクチャ（現時点での判明事項）

| ノード | 状態 | 備考 |
|---|---|---|
| QY-NODE-07 | ACTIVE（応答なし） | ZeroDayが使用中。最新世代 |
| QY-NODE-01〜06 | SILENT | 呼び出しフォーマットが合っていない可能性（テルの仮説） |

- NODE-07のプロトコル継承元は「別の権限体系」下に隔離されており読み出せない
- 番号の意味：01が最古世代、07が最新世代（ep9でテルが言語化）
- NODE-01〜06は「応答していない」のではなく「NODE-07形式では届いていない」という解釈が有力（N-01）

### 設定資料：七十三年前に関して現時点で確定している事実

**確定事実**（ep7〜ep9）
1. 七十三年前に「もう一人」の存在が記録に残っている（F-35、ep8でイレーネが断言）
2. その人物は「黒板に触れた」（F-40、ep9章末で明らかになった記録の一行目）
3. その人物の記録の残し方がNODE-07の形式と同じ（ep7でプロトコル形式の一致が判明、F-26）
4. 「もう一人」の記録はroot権限では読めない「別の権限体系」下の領域にある（F-37、F-34）
5. ZeroDayは七十三年前の形式を「部分的に引き継いでいる」（テルの推論、ep9）

**未確定・これから明かされる事項**
- 「黒板に触れた」が具体的に何を意味するか（転生者か / root権限保持者か / 神から特権を与えられた者か）
- その人物の正体
- 七十三年前に何が起きたか（F-26の回収につながる）

### 設定資料：権限体系（root権限より上の構造）

世界設定（§2）と技術的描写（ep9）を統合すると以下の権限体系が浮かぶ：

```
[神の権限体系] ← ep9で初めてその存在が示唆された領域
      ↓
[テルのroot権限] ← これまでほぼ全てにアクセスできていた
      ↓
[一般術式ユーザー]
```

- 七十三年前の記録が「別の権限体系」下に置かれているということは、神のシステムより外側か、あるいは同等の別系統の管理下にある可能性がある
- テルが「神のシステムの外側から介入する存在」（F-33、F-07）であるという設定と照合すると、「もう一人」も同様の「外側の存在」だった可能性が浮かぶ
- ただしF-07・F-12・F-33は最終章で回収予定。ep10では「その可能性を示唆する描写」にとどめ、確定させない

### 設定資料：聖務局の内規（§7）

- 神のシステムへの「改変」は正式には重大な異端行為
- ただし緊急時に限り「修復」名目で黙認される慣例がある（聖務局上層部のみが知る）
- テルはこの慣例を正式に説明されていない（F-02の回収への伏線）
- イレーネがバルナバスの命令を超えた行動を取ったこと（F-39）は、この内規との緊張関係を内包する

### 設定資料：地理・季節

- 舞台は大聖核周辺の聖都アルカナム（大陸中央部）
- ep9の描写：「冬の終わりの、まだ重い空」「灰色の空」
- ep10は冬の終わり〜春の始まりの時期として整合が取れる

## 3. ep10で意識すべき設定上の制約と矛盾リスク

### 制約1：テルのキャラクター立場

テルはまだ「新入りの下っ端」であり、展開を急いではいけない（world-settings.md §11）。  
ep9でイレーネに役割（形式の特定担当）を与えられたが、あくまでイレーネの指示下での作業である。  
黒板で自力探索はできるが、聖務局の意思決定ラインに正式に入っているわけではない。

### 制約2：イレーネの感情表現の抑制

協力フェーズ（ep7〜第1章末）に突入したが、感情的な接近は第2章まで慎重に抑制する。  
「前世」に踏み込む台詞は書かない。イレーネが見せる変化は「行動」で示す（台詞で感情を語らせない）。

### 制約3：権限体系の「答え」を出さない

F-37（root権限より上の権限体系）の「正体」は最終章で回収予定のF-07・F-12と連動している。  
ep10では「その存在を認識し、さらに問いを深める」段階にとどめる。答えを示唆しすぎると最終章が台無しになる。

### 制約4：「黒板に触れた」の意味を確定させない

F-40は「転生者か / root権限保持者か / 神から特権を与えられた者か」という複数の解釈を残したまま進む必要がある。ep10でテルが考察を深めることは自然だが、確定的な答えは出さない。

### 制約5：バルナバスの目的を明かさない

F-06・F-38はそれぞれ第2章以降で回収予定。バルナバスが何を知り何を目指しているかは、「読めない表情」「沈黙」「態度を明かさない」という描写で維持する。

### 矛盾リスク1：ARKの定義が未確定

章管理台帳の用語辞典に「ARK（未定義・要追記）」として残っている。ep9でも`list --node=ARK/*`というコマンドが登場している。ep10で引き続き使用する場合は、作中での定義を一貫させる必要がある。現時点ではノードの集合体（QY-NODEを束ねる上位識別子）として描写されているように読めるが、正式定義がないため拡張には注意が必要。

### 矛盾リスク2：副官の職称が未定義

章管理台帳に「副官（バルナバスの部下の職称）（未定義・要追記）」として残っている。ep10で登場させる場合は同じ「副官」という表記を維持する。

### 矛盾リスク3：シリア不在の期間

シリアはep7以降登場していない。ep10でも登場しない場合、読者がシリアの存在を忘れる前に、何らかの言及を入れることが望ましい。

## 4. ep9クリフハンガーから自然につながるための設定的根拠

クリフハンガー：『七十三年前、その者は黒板に触れた』という一行目をテルが読んだ

### 接続の論理

ep9直前の状態をまとめると：

1. テルは前夜に「root権限より上の権限体系が存在する」という認識に至った
2. テルは翌朝セルダ村の男と面談し「悪人ではない・インフラが壊れていた」という内部認識を確立した
3. 会議でテルは「呼び出しフォーマットが合っていない可能性」を提起し、形式特定の担当に指名された
4. 廊下でイレーネがバルナバスの命令を超えた独自判断でテルに記録を手渡した
5. そして「黒板に触れた」という記録の一行目

「黒板に触れた」という言葉がテルに与える衝撃の根拠は設定上明確：
- 黒板はテルが知る限り自分だけが使える特殊な物理コンソール（root権限アクセス手段）
- 七十三年前にも同じものを使った者がいた＝前世の記憶（自分は「転生した」のに、なぜ別の誰かも同じ道具を持っているのか）という疑問に直結する
- F-07（root権限取得がなぜ成功するか）、F-26（七十三年前の修復者）、F-35（もう一人の正体）、F-40（黒板に触れた記述）の四つの伏線が一点に収束する瞬間

### ep10冒頭のトーン設計に使える設定

- テルは一行目を読んで止まっているところから始まる（「廊下に一人」「手の中の紙」という状態のまま）
- 続きの行がある（複写には「何行か並んでいる」と描写された）
- 時間軸：冬の終わり、昼に向かいつつある午前中。廊下の光は「午前の角度」だった
- テルの内部状態は「口の中が乾いた・喉の奥が軽く詰まる感覚・前世でログの欠損に気づいた瞬間と同じ」という身体感覚に近い

## 5. 「七十三年前の記録」「黒板に触れた者」「root権限より上の権限体系」の設定的整理

### 5-1. 七十三年前の記録について

| 項目 | 確定事実 | 根拠 |

| 存在 | 七十三年前に「記録が残っている」 | ep4でイレーネが即座に反応（F-05）、ep7〜9で徐々に具体化 |
| もう一人 | 七十三年前に「もう一人」の人物が存在した | ep8でイレーネが断言（F-35） |

### 5-2. 「黒板に触れた者」の設定的解釈（選択肢）

プロットディレクターへの参考として、設定的に成立する解釈の候補を整理する：

| 解釈 | 設定との整合性 | 伏線との連動 |
|---|---|---|
| A：転生者（テルと同じ外側の存在） | F-07・F-12・F-33と一致。「神のシステムの外側から介入する存在」が複数いた可能性 | 最終章の真相開示と直結 |
| B：神が特権を与えた在来の人物 | 七十三年前の聖務局の黙認慣例（F-27）と連動する可能性 | F-27の回収と組み合わせると機能する |
| C：ZeroDayの前身的人物 | ZeroDayも転生者第一号という設定（§9最終章）と照合すると時期が合わない可能性 | F-09・F-11と連動するが年代的に矛盾の可能性あり |

**要確認事項（矛盾リスク）：** ZeroDayの転生時期と七十三年前の時系列
- world-settings.md §6によるとZeroDayは「転生順：第一号。テルより遥かに長くこの世界で生きている」
- ZeroDayが七十三年前に既にこの世界にいた可能性はあるが、「七十三年前の記録の者」がZeroDayである場合、ZeroDayは七十三年以上生きている計算になる（外見年齢30代前半とは矛盾する可能性）
- 解釈Cは採用に注意が必要。プロットディレクターに確認を推奨する

### 5-3. root権限より上の権限体系について

**ep9で確認された事実**
- テルの黒板は「ほぼあらゆる領域」に通じていた（ep1〜ep9）
- ep9で初めて「アクセス権限不足」という応答が返ってきた
- NODE-07のプロトコル継承元が「別の権限体系」下にある

**設定との整合性**
- world-settings.md §2の「魔法の本質」では神が世界制御システムを構築したと定義されている
- F-07の伏線（なぜテルのroot権限取得が成功するか）は「テルが神のシステムの外側から介入する存在」（F-33）に帰着する
- 「root権限より上の権限体系」は「神の権限体系」そのものである可能性が高いが、最終章まで確定させない

**ep10での描写方針**
- テルが「自分のroot権限より上に何かがある」という事実を認識したまま、その「何か」に向かってアプローチしていく段階
- 黒板が弾く→別のアプローチを試みる→新たな「問い」が見つかる、という展開が設定的に自然
