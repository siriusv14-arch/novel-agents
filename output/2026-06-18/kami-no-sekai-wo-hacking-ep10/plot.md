- F-42（仮）：複写には後から加えられた書き込みがある（誰が加えたかは不明）

## 章末の引き（先に設計する）

テルが黒板で再照合を試み、ep9と同じ RECORD_BOUNDARY エラーが返ってくる。しかし今回は
「エラーの返し方」がわずかに違う。前回と同じコマンドで叩いたのに、応答フィールドが一行増えていた。

```
[ERROR: RECORD_BOUNDARY]
[no prior index accessible]
[最古層: NODE-07]
[参照可能なフォーマット仕様: 非公開 / 問い合わせ先: UNDEFINED]
```

「問い合わせ先: UNDEFINED」。
前回は出なかった行だ。

エラーコードが変わったのではない。テルが何かを動かしてしまったのか。
あるいは、向こうが気づいたのか。

章末、テルはその一行を手元の羊皮紙に書き写す。黒板の文字は消えていく。

## 場面構成

### 場面1：廊下での続き読み（冒頭、ep9クリフハンガー直後）
**想定字数**: 1,000〜1,400字
**目的**: クリフハンガーの衝撃を即座に受け止め、F-40・F-35の三点セットを起動する

**内容**:
- ep9の末尾「廊下に一人、手の中の紙」から一秒も置かずに始まる
- テルが複写の二行目以降を読み進める
- 複写の内容（書き手が書いたこと）:
  - 一行目: 「七十三年前、その者は黒板に触れた」（ep9章末から継続）
  - 二行目: 「ノードとの接続様式は、現行のものとは異なる。記録を複数の場所に分けて残した」
  - 三行目: 「その目的について、この写しには記されていない」（← F-41仮として機能する。「なぜ分割したか」が問いとして残る）
  - ここで複写の文字が一行だけ別の筆跡で書き足されている（← F-42仮。誰が書いたか不明）
  - 書き足された行は「この先を知りたければ、形式から辿れ」という一文
- テルの内部反応:
  - 「記録を分割して残した」という行動様式への注目
  - 「これは、自分と同じように黒板に触れた人間が書いた記録だ」という仮説の言語化（F-40の要件を満たす）
  - ただし「転生者か / root権限保持者か / 神が与えた特権者か」という問いは保留のまま。仮説は「同じ存在かもしれない」止まり
  - F-09との連絡: ZeroDayの脅迫文「神の不自由な理を停止させた」という言い回しと、この古い複写の文体が奇妙に近い、という気づきが一瞬過ぎる（深追いしない）
- 廊下の光の描写（冬の終わりの午前の角度）で場の体温を維持する

**注意事項**:
- 「黒板に触れた」の意味を確定させない
- 書き足された行（F-42）の筆跡について「イレーネか他の誰かか」の判断はテルも読者もしない

### 場面2：テルが自室に戻り黒板で照合（前半の核心）
**想定字数**: 1,200〜1,600字
**目的**: F-37の「設計として存在する壁」をテルが認識する。F-02の内部葛藤を一文入れる

**内容**:
- 部屋に戻ったテルが黒板を膝に置く（ep9と同じ始まり方だが意図的に少し変える）
- 複写の二行目「接続様式は現行と異なる。記録を複数の場所に分けて残した」を手がかりに、別角度からNODE-07以前へのアクセスを試みる
- コマンド試行の流れ:
  ```
  > trace --target=NODE-07 --field=record_format --split=enabled
  ```
  返答: `[ERROR: RECORD_BOUNDARY]` （ep9と同じ）
  
  角度を変える:
  ```
  > query --origin=UNDEFINED --format=legacy
  ```
  返答: `[PARAMETER_UNDEFINED: legacy]`（「古い形式」というパラメータ自体が定義されていない）

- F-02の一文: 「これは修復か、改変か」という内部の声が一瞬だけ浮かぶ。テルはそれを押しとどめる。「どちらでも、やる」ではなく「今はその分類が問題ではない」という判断。（感情的な反発ではなく実務的な先送りとして描く）

- F-01との連絡: この時点でテルの頭の片隅に、昨日の会議で誰かが言った「不具合発生の頻度がまた上がっている」という一句が浮かぶ。（F-01の進展として機能させる。直近の報告として自然に触れる）

- 黒板を閉じてから、複写の書き足された行を手元で読み返す。「形式から辿れ」。
  「形式」を辿るには、形式そのものがどこかに残っていなければならない。
  残っているとしたら、どこに？

**注意事項**:
- F-02の内部葛藤は過度に膨らませない。一文で示して先に進む
- 「別の形式でアクセスすれば読める」という楽観的な結論は出さない。「形式がどこにあるか」が次の問いとして積み上がる

### 場面3：イレーネとの短い接触（廊下か小部屋）
**想定字数**: 1,000〜1,300字
**目的**: F-39（なぜ渡したのか）の問いを立てる。F-06（バルナバスの視線）を1カット入れる。シリアへの言及で矛盾リスク3を解消する

**内容**:
- 午後、テルがイレーネを探して声をかける（あるいはイレーネから呼ばれる形でも可。ライターの判断に委ねる）
- テルが複写について確認する:
  - 「書き足された行がありますが、これは」
  - イレーネの返答: 「私ではない」 端的に。それ以上は言わない
  - テルの内部: 「では誰が」という問いが浮かぶが、口には出さない

- F-39の問いを立てる場面:
  - テルが「なぜ私に渡したのですか」と直接は聞けずにいる（聞けない理由は「聞いてもイレーネが答えないことが分かっているから」ではなく「聞くべきかどうか、まだ分からないから」という内部描写で処理する）
  - ただし、テルが「渡した」という事実の重みに気づいている描写は入れる。「バルナバスの命令を超えた判断。それは何を意味するのか」という問いが内部で静かに立つ

- イレーネが一言、実務的な情報を落とす:
  「シリアの状態を確認しておいて。感知能力に変化があるかもしれない」
  （シリアへの言及でF-04・F-10の気配を読者に思い出させる。登場はまだない）

- F-06（バルナバスの視線）: この場面か、またはその直後の廊下で、テルがバルナバスとすれ違う。バルナバスがテルに対して通常の会釈以上の何かをするわけではない。ただ、「一瞬、止まった」か「通り過ぎた後、足音が少し遅かった」という描写を一行入れる。テルが「この人は、自分について、自分以上に何かを知っているのかもしれない」という感覚を内部で初めてはっきり持つ

**注意事項**:
- イレーネの感情表現は出さない。すべて「行動」と「端的な台詞」で見せる
- バルナバスの目的・動機に踏み込まない。視線と動作だけ

---

### 場面4：黒板で再照合 ―― 壁が変わった（章末の核心）
**想定字数**: 1,200〜1,500字
**目的**: F-37の深化と章末クリフハンガーの設置

**内容**:
- 夜、テルが再び黒板を開く
- 「形式から辿れ」という書き足しの言葉を手がかりに、形式の記述自体を探すコマンドを試みる
  ```
  > describe --target=NODE-07 --field=format_spec
  ```
  返答:
  ```
  FORMAT_SPEC: [継承元参照]
  継承元: [非公開 / アクセス権限不足]
  ```
  NODE-07の形式仕様はそれ自体がNODE-07以前の継承元を参照するだけで、自立した定義を持っていない。
  
  テルの内部: 「NODE-07の形式は、NODE-07より前の形式を引き継いでいるだけで、形式そのものはここにはない」

- ep9と全く同じコマンドを打ってみる（比較のため）:
  ```
  > trace --target=NODE-07 --history=before
  ```
  返答:
  ```
  [ERROR: RECORD_BOUNDARY]
  [no prior index accessible]
  [最古層: NODE-07]
  [参照可能なフォーマット仕様: 非公開 / 問い合わせ先: UNDEFINED]
  ```

- テルが止まる。前回と違う行が出た。「問い合わせ先: UNDEFINED」。
  ep9では出なかった行だ。コマンドも入力も何も変えていない。
  「向こうが応答の仕方を変えた」のか。
  「自分が何かを動かしたから、向こうが反応した」のか。
  あるいは「複写を読んで、何かのトリガーを踏んだ」のか。

- テルが羊皮紙にその一行を書き写す。黒板の文字は消えていく。
  「UNDEFINED」という言葉が手元の紙に残る。
  未定義。問い合わせ先が、存在しない。
  それとも、「まだ」存在していないのか。

- テルの最後の内部独白（一文）:
  「七十三年前の誰かが形式から辿って、何かに届いたなら」
  
  そこで止まる。

## 書き出しパターンの確認（直近との差別化）

- ep9冒頭: 「廊下の石が冷えていた。」（風景・触覚から入る）
- ep8冒頭: 朝の会議室から入るパターン
- ep7冒頭: トレースバックの作業から入るパターン

ep10の書き出し案: ep9の廊下の継続から入る（時間が断絶していない）。ただしep9の「廊下の石が冷えていた」という風景描写との重複を避け、テルの「手の中の紙」という物体の感触から入る。または複写の二行目の「文字」から入り、目線が手元にある状態からスタートする。具体的な書き出しはライターの判断に委ねる。

## キャラクター別の口調・行動指示（ライターへ）

### テル
- 推測・仮説表現が多い。一文で結論を言い切らない
- 内部独白は括弧（）で処理（ep9に準拠）
- コマンド操作の描写はep9のスタイル（コードブロック + 返答ブロック）で統一
- 「前世の記憶の断片」が浮かびうる精神状態にあるが、今章では一か所に絞る（場面2の黒板照合中のみ可）

### イレーネ
- 端的で断定的。余計な感情表現なし
- 「〜ね」「〜でしょう」「〜確認する」「〜見ておく」「〜記録しておく」の口調
- 「私ではない」「必要なことだから」のような短い答えで場面を切る
- 感情を台詞で語らない。変化は行動でのみ示す

### バルナバス
- 今章は「通り過ぎる」だけ。台詞なし or 最小限（「ご苦労」一言程度）
- 視線や動作の描写のみ。謎の保持を最優先とする

## 設定的な注意事項（ライターへ）

1. **「黒板に触れた」の意味を確定させない**: テルが「同じ存在かもしれない」と仮説を立てる段階にとどめる。「転生者だ」「root権限保持者だ」という断言は書かない

2. **ZeroDayとの関係**: F-09の連絡（文体の近さ）は「気づきが過ぎる」レベル。深追いしない

3. **ARKの定義**: ep9に準拠して `list --node=ARK/*` 形式を維持。定義は拡張しない

4. **副官の職称**: 今章にバルナバスの部下が登場する場合は「副官」で統一

5. **シリア**: 今章に直接登場しない。イレーネの台詞で存在を示唆するのみ（場面3参照）

6. **「問い合わせ先: UNDEFINED」のフィールド**: ep10で新たに現れた応答行。テルが驚く根拠として「ep9では出なかった」という比較を使う。ただしこのフィールドの意味は確定させない

7. **原本複写の続きの内容（用語統一）**: この章で初めて引用する二行目・三行目および書き足しの行は、本文中で初出となる新規テキスト。イレーネが「原本を写した複写」と表現したとおり「インクは新しいが文体は古い」という視覚的描写を維持する
