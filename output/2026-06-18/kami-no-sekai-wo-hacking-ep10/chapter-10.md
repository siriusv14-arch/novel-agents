ep.10　第1章 第7話：続きの文字 ―― 壁の向こうで、誰かが書いた

『七十三年前、その者は黒板に触れた』

その一行から、目が動かなかった。
廊下に、まだ一人だった。
窓から差す光が、午前の角度のまま、紙の上を斜めに撫でている。

息を吸って、視線を二行目に落とした。

『ノードとの接続様式は、現行のものとは異なる。記録は、複数の場所に分けて残された』

文字の運びは、緩やかだった。
慌てていない。説明しようとしている書き手の文ではない。何かを「残しておく」ための、淡々とした手だった。
インクは新しい。けれど、文体は古い。イレーネの言ったとおりだ。

（……記録を、分けて残した）

そこで、一度止まった。

一か所に置かなかった。複数の場所に分けた。
理由は書かれていない。書き手がそれを伏せたのか、写した側が落としたのかは分からない。けれど、行動だけが残っている。残し方そのものに、意図がある。

（……隠したのか。あるいは、一か所が消されても、別の場所から辿れるように）

前世で、同じことをする人間を知っていた。
バックアップを一か所に置かない。本番系と別の物理に、別の系統で逃がしておく。消されることを、最初から計算に入れている人間のやり方だった。

視線を、三行目に移した。

『その目的について、この写しには記されていない』

そこで、行が終わっていた。
複写は、そこまでだった。

——のはずだった。

三行目の下に、もう一行ある。
さっきまでの三行とは、明らかに筆跡が違う。
インクの色も、わずかに濃い。後から、別の手が書き足したものだ。

『この先を知りたければ、形式から辿れ』

指先が、紙の端で止まった。

（……これは、誰が)

写した人間が書いたのか。
それとも、写された後に、別の誰かが書き加えたのか。
分からない。判断する材料がない。

ただ、書いてある。
「形式から辿れ」。命令ではなく、助言の語調だった。読む者がいることを、前提にしている。

目を、一行目に戻した。

『七十三年前、その者は黒板に触れた』

黒板。
自分の知る限り、それを使えるのは、自分だけのはずだった。神のシステムに、内側ではなく外側から触れる、あの物理コンソール。それを、七十三年前にも、誰かが使った。

記録を複数の場所に分けて残し、消されることを計算に入れて書いた人間。
それは、自分と同じように黒板に触れた人間が書いた記録だ。

（……「同じように」）

そこまで言語化して、止めた。

同じ道具を使った。それは分かる。
けれど、「同じ存在」だとは、まだ言えない。
転生してきた人間なのか。神がその者にだけ特権を与えたのか。あるいは、自分の知らない別の経路で、root権限に辿り着いた在来の人間なのか。

可能性はいくつもあって、どれも潰せていない。

（……仮説は、止めておく)

仮説を一つに決めてしまえば、それ以外を見なくなる。前世で、何度もそれで足元をすくわれた。

ただ、一つだけ、頭の片隅で、別のものが引っかかっていた。

——『神の不自由な理を停止させた』。

ZeroDayの脅迫文の一節だった。あの言い回し。
そして、この古い複写の文体。
似ている、とまでは言わない。けれど、温度がどこか近い。同じ流派の文章を読んでいる時の、あの感覚に似ていた。

（……気のせい、かもしれない)

深追いはしなかった。今はまだ、その糸を引く時ではない。

紙を、二つに折らないように、そっと手のひらに伏せた。
廊下の光は、まだ午前のままだった。

---

部屋に戻った。

机の上は、昨夜のままだった。広げた羊皮紙、インクの瓶、読みかけの設定書。
椅子に座る前に、黒板を取り出していた。昨夜と、同じ手順だった。

膝の上に黒板を置いた。
複写を、机の角に伏せて置く。「記録は、複数の場所に分けて残された」。その一行を、頭の中で何度か折り返してから、指をコンソールに置いた。

別の場所に分けた、ということは、NODE-07の形式とは別の入り口があるということだ。
昨夜は「歴史をさかのぼる」角度で叩いて、壁に当たった。今度は、角度を変える。

```
> trace --target=NODE-07 --field=record_format --split=enabled
```

返事を待った。

```
[ERROR: RECORD_BOUNDARY]
```

同じ壁だった。
ep9と、寸分違わない返し方。記録の境界。ここから先は読めない。

息を吐いた。
正面からは、やはり通らない。

角度を、もう一段変える。
「現行の形式」ではなく、「古い形式」そのものを名指しして呼んでみる。

```
> query --origin=UNDEFINED --format=legacy
```

```
[PARAMETER_UNDEFINED: legacy]
```

止まった。

「古い形式」という、そのパラメータ自体が、定義されていない。
システムは「legacy などというものは知らない」と答えている。古い形式が「読めない」のではない。古い形式という概念が、そもそもこのシステムの語彙に存在しない。

（……ここには「古い形式」という言葉すら、ない)

新しい形式しか知らないシステムに、古い形式を尋ねている。
通じるはずがなかった。

指が止まった。
その隙間に、別の声が、一瞬だけ浮かんだ。

——これは、修復か。改変か。

読めない領域を、読もうとしている。塞がれているものを、こじ開けようとしている。
それは、壊れたものを直す手つきなのか。それとも、触れてはいけないものに手を伸ばす手つきなのか。

（……今は、その分類は、問題じゃない)

押しとどめた。感情で押しとどめたのではない。順序の問題だった。先に何があるかを見てから、それが修復か改変かを考えればいい。今、ここで線を引く必要はない。

その代わりのように、別の一句が浮かんだ。
昨日の会議の、隅のほうで誰かが言っていた言葉だった。

——不具合の発生頻度が、また上がっている。

地図の前で、防衛担当の一人が、ほとんど報告の前置きのように言った一行。誰も深くは拾わなかった。けれど、頻度が「また」上がっている、と言った。前にも上がって、間隔が、少しずつ縮まっている。

（……それも、いつか、見ておかないといけない)

頭の隅に置いて、黒板を閉じた。

複写を、机の角から取り戻す。
書き足された一行を、もう一度読んだ。

『この先を知りたければ、形式から辿れ』

形式から辿れ。
辿るには、辿る先に、形式そのものが残っていなければならない。
NODE-07は、その形式を「引き継いで」いる。引き継いだ、ということは、引き継ぎ元がどこかにあるということだ。

（……形式そのものは、どこに残っている)

それが、次の問いだった。

午後、イレーネを探した。

会議で使った小会議室の前で、ちょうど出てくるところに行き合った。羊皮紙を一枚、手にしている。色の古い、あの種類の紙ではない。今日の業務のものだった。

「イレーネさん」

足を止めた。イレーネも止まった。

「少し、いいですか」

「手短にね」

複写を、手のひらの上に出した。折り目はつけていない。

「いただいた複写のことです。三行目の下に、もう一行、書き足された行がありました。筆跡が、ほかと違っていて」

イレーネの視線が、紙の上を一瞬だけ走った。
読んだ、というより、確認した、という速さだった。

「私ではない」

端的だった。それ以上は続かなかった。

（……では、誰が)

問いが浮かんだが、口には出さなかった。出したところで、イレーネがそれを知っているなら、もう言っている。知らないなら、聞いても同じだ。

代わりに、別のことが、胸の奥で静かに立ち上がっていた。

この複写を、イレーネは自分に渡した。バルナバスの命令は調査までで、渡すかどうかは自分が決めた、と言った。あれは、命令の範囲を超えた判断だった。

（……なぜ、僕に)

聞けなかった。
聞けない理由は、イレーネが答えないと分かっているから、ではなかった。聞くべきかどうかが、まだ自分の中で決まっていないからだった。
渡された、という事実の重みだけが、手のひらに残っている。命令を超えてまで、この紙を、自分のところに置いた。それが何を意味するのか、まだ測れていない。

イレーネが、羊皮紙を脇に持ち替えた。

「形式の特定は、進んでいる?」

「……正面からは、まだ。壁の返し方が、昨夜と同じです。別の角度を探しています」

「そう」

それだけだった。咎める響きはなかった。進捗を確認した、という事務だった。

イレーネが、歩き出しかけて、半歩のところで止まった。

「シリアの状態を、確認しておいて」

「……シリアを、ですか」

「感知能力に、変化があるかもしれない。ノードが動き始めているなら、いちばん先に反応するのはあの子よ。記録しておいて」

「分かりました」

イレーネは、もう振り返らなかった。
背筋を伸ばして、廊下を歩いていった。

その後ろ姿が角を曲がる前に、向こうから一人、歩いてくるのが見えた。
バルナバスだった。

すれ違う。
会釈をした。バルナバスも、ごく浅く頷いた。それだけのはずだった。

すれ違いざま、バルナバスの歩みが、一瞬、緩んだ。

未定義。

あるいは——「まだ」存在していないのか。定義されていないだけで、いつか定義されうるものなのか。それとも、永遠に定義されない、という意味なのか。

『参照可能なフォーマット仕様: 非公開 / 問い合わせ先: UNDEFINED』

用語解説

フォーマット仕様（format_spec）：本来は、データがどんな決まりで並んでいるかを定義した「設計図」のこと。プログラムは、この仕様を見て初めて、並んでいるデータを正しく読める。仕様が分からなければ、データはただの記号の羅列になる。この話でテルが叩いた format_spec が「継承元を参照せよ」としか返さなかったのは、NODE-07が自分の読み方を自分では持たず、もっと古い世代の仕様を引き継いでいるだけだ、ということを意味している。設計図がここにない以上、いまの聖務局はNODE-07以前を「読む」ことができない

UNDEFINED（未定義）：本来は、参照しようとした名前や値が、システムのどこにも定義されていない時に返ってくる応答。「エラー（読めない）」とは少し違う。「読めない」は対象が存在することを前提にしているが、「未定義」は、その対象がそもそも定義されていないことを示す。この話で「問い合わせ先: UNDEFINED」が返ってきたのは、壁の向こうへ問い合わせる相手が「定義されていない」という意味であり、相手が「いない」のか「まだ登録されていないだけ」なのかは、この応答だけからは判別できない。テルがその一行に引っかかったのは、未定義という言葉が、不在とも、未到来とも、どちらにも読めるからである

レコードバウンダリの応答行（four-line response）：同じ問い合わせに対して、システムの返す行数が増減することがある。これは、システムの内部状態が変わったか、あるいは観測者の操作によって何かが書き換わったことを示す手がかりになる。この話で、昨夜は三行だった応答に四行目が加わったのは、テルの操作か、あるいは「向こう側」の状態変化のどちらかが起きたことを意味する。同じ入力に対する出力の差分は、システムの内側で何かが動いた、ほぼ確実な証拠になる
