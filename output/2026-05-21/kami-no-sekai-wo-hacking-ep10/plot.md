**「古い書き方 ―― 七十三年前の黒板と、空白の行」**

サブ案: 「読める行と、読めない行」 / 「その者は黒板に触れた ―― 継承の痕跡」

## あらすじ（約200字）

廊下でイレーネから受け取った七十三年前の原本複写。一行目「その者は黒板に触れた」を手に、テルは部屋に戻り記録を読み始める。記録は「読める行」と「意図的に消されたか空白になっている行」が混在する構造になっており、もう一人の行動の輪郭は見えてくるが、正体への答えは出ない。翌日、ノード形式の特定作業を続けるテルのもとにシリアが来る。シリアがQY-NODE信号の変化を感知する一幕の中で、テルは記録の「古い書き方」とノードの「古い形式」が同じ根から来ている可能性を感じ取る。章末は新たな空白の行――消えた記録の存在――を前に、問いがさらに深まる引きで終わる。

### 場面1：一行目の咀嚼（冒頭）

**目的**
ep9章末の衝撃を着地させる。F-40（「黒板に触れた」の意味）とF-07（root権限の問いの再定義）を内部思考で処理する。

**登場人物**
テルのみ

**場所**
聖務局の自室（机・黒板）

**起きること**

- テルは廊下から部屋に戻り、受け取った複写を机に置く
- 一行目を読み返す。「黒板に触れた」という言葉が意味するものを、前世のIT用語で脳内整理しようとする
  - 「黒板に触れた」＝神のシステムに直接アクセスした、root権限を行使できた、ということか
  - 「自分だけではなかった」という認識が立ち上がる（F-07の問いの再定義）
  - ただし、転生者なのか、別の権限保持者なのか、神に近い存在なのかは分からない
- 続きを読もうとして、二行目以降の構造に気づく
  - 記録は「書かれた行」と「空白の行（消されたか、最初から書かれていないか判別できない）」が交互に混在している
  - 読める行: 「接続を試みた」「失敗した」「別の経路を探した」という短い記録の断片
  - 空白の行: 行の位置だけがあり、文字がない。インクの痕がわずかにある行もある
- 内部思考: 消したのか、神のシステムが読めない形式なのか、それとも最初から存在しないのか
- F-09への接続: ZeroDayの脅迫文「神の不自由な理を停止させた」という言葉がふと浮かぶ。この記録の人物も、「理」と呼ばれる何かの外側に立っていたのではないか、という予感が一行で入る
- F-01への接続: 写し作業の合間にインシデントログを確認する一行。不具合頻度がまた縮まっている、という数字が目に入る

**伏線処理**
- F-40: 「黒板に触れた＝root権限を行使できた存在」という認識が確立（大きく進展）
- F-07: 「自分だけではなかった」という一文を内部思考として入れる（問いの再定義）
- F-35: もう一人の行動の断片（接続試行・失敗・別経路探索）が見えてくる（進展）
- F-09: ZeroDayの脅迫文を想起する一行（軽く触れる）
- F-01: 不具合頻度の数字を確認する一行（軽く触れる）

**Show, don't tellの注意点**
- 「驚いた」「衝撃を受けた」と書かない
- テルが複写を持ったまま椅子に座らずにいる、指が一行目の上で止まっている、という所作で示す
- 前世のIT経験を使った内部整理の語り口（「root権限で触れる」という言い方）でテルらしい感情の距離感を保つ

### 場面2：記録の壁（翌朝 / 作業場）

**目的**
記録に「読めない部分」が構造として存在することを描写し、F-37（上位権限体系）・F-27（黙認慣例の起源）への新規伏線を埋める。記録の物理的な「空白の行」がそのまま謎として機能する。

**登場人物**
テルのみ（黒板との作業）

**場所**
聖務局の作業室（ノード形式特定の担当作業場）

**起きること**

- 翌朝、テルはノード形式特定のための黒板作業を始めている
- 昨夜読んだ記録の続きを机の端に広げたまま、並行して作業している
- 黒板でノード形式を探ろうとする:
  ```
  > probe --format=ancient --target=NODE-01
  ```
  返答がない。エラーでもなく、無応答。「無応答」と「拒否」の違いについての内部思考
- 記録の続きを読む場面で、ある行に気づく:
  - 「黒板は、古い書き方でなければ応答しない」という一行が読める
  - その下の行が空白になっている
  - 「古い書き方」が何であるかは書かれていない
- これがノード形式不一致仮説と直結していることをテルが認識する
  - もう一人も、古いフォーマットを持っていたのか
  - ならば自分が今やっているノード形式の探索は、七十三年前に同じ人物がやったことを、逆からなぞる作業なのかもしれない
- イレーネへの問いを一瞬考えて、「渡した理由を聞けなかった」という宙吊りに留まる（F-39の処理: テルは問えなかった）
- F-05への接続: イレーネがこの記録の「古い書き方」という行を先に見ていたとしたら、すでに何かに気づいていたはずだ、という推測が内部に浮かぶ

**伏線処理**
- F-37: 記録の「空白の行」＝上位権限で消された可能性の示唆（新規伏線として補強）
- N-01: 「古い書き方でなければ応答しない」という記録の一行が、ノード形式不一致仮説と接続（進展）
- F-34: 「古い書き方」という言葉がNODE形式の正体への糸口として機能
- F-39: 「渡した理由を聞けなかった」という宙吊り描写（今章での答え出しなし）
- F-05: イレーネが先にこの行を見ていたはずだ、という推測（一行程度）

**Show, don't tellの注意点**
- 「謎が深まった」という地の文を書かない
- 黒板が無応答のまま画面に何も返ってこない、という描写そのものが謎を示す
- テルが「聞けなかった」という事実を、「聞こうとして廊下に出て、引き返した」という行動で見せる

### 場面3：シリアが来る（同日 午後）

**目的**
シリアを自然な動機で作業場に登場させ、QY-NODE信号の感知を描写する。F-04（感染時期の一致）への接続と、シリアが場面にいることで空気が変わる描写を置く。

**登場人物**
テル、シリア（アルリックが送ってくる形でも可）

**場所**
作業室 / 廊下

**シリアが来る動機の設計**
シリアは聖務局の保護下にあるが、昼の食事の時間が終わった後ひとりになると「なんかここ、変な感じがする」とテルの作業室の方向に引き寄せられる感覚があった。アルリックか別の騎士が「あなたのところに来たがっている」と連絡する形で自然に合流させる。

**起きること**

- シリアが作業室の扉から顔を出す。テルが振り返る
- シリアの口調:
  - 「……なんか、ここ。変な感じがして」
  - 「来ちゃいけなかった？」
  - テルが「来ていい」と言って、机の隣に椅子を出す
- テルが黒板で再度プローブコマンドを試みる。その瞬間、シリアの体が固まる
  - 「……あ。なんか、来た」
  - 「引っ張られる感じ。いつもと、ちょっと違う」
  - 「重い。ふつうと、なんか層が違う感じ」
- テルが黒板の反応を確認するとコマンドは無応答のまま。つまりシリアが感知したのは、黒板が「返答できていない」側の信号
  - テルの内部思考: シリアはNODE-01の側の信号を感知している。黒板が届いていない、古い形式の領域から何かが出ている
- シリアの感知が止まる。「……消えた」
- テルがシリアに「いつごろから、こういう感覚があった」と聞く
  - シリアが「……二年くらい、前から、かな」と答える
  - F-04への接続: テルの内部思考として「ZeroDayの活動開始時期と重なる。偶然ではないかもしれない」という一行が入る
- 黒板の作業に戻るテルの机の端に、複写の束がまだ広げられている
  - シリアが文字を見て「なに、これ」と聞く
  - 「古い記録」とだけ答える
  - シリアが「……読めない字がある」と言う。テルが確認すると、シリアが指差した行は、テルには普通に読める行だった
  - 「読めないって、どのへん？」「……ここ。字がある、でも、なんか、浮いてる感じ」
  - テルの内部思考: シリアには文字として見えていない行がある。感染の痕跡が、別の形式の記録を見せているのか、それとも消された行を別の感覚で認識しているのか

**伏線処理**
- F-19: QY-NODE信号の感知（継続描写・進展）
- F-04: シリアの感染開始時期とZeroDayの活動開始時期の一致（内部思考一行）
- F-10: シリアがZeroDayの信号を感知しているという事実の継続描写
- 新規伏線候補: シリアが「読めない行」を別の感覚で認識する描写（第2章以降への伏線として設置）

**Show, don't tellの注意点**
- シリアの感知を「心地よい」とも「怖い」とも書かない。シリア自身が言葉にできていない感覚として描く
- 「引っ張られる感じ。重い。層が違う」という不完全な言語化で描写する
- テルが「どういうことだろう」と地の文で説明しない。次のコマンドを打つ、記録を手に取る、という行動で思考を示す

### 場面4：もう一つの空白（夕方 / 廊下）

**目的**
章末の引き。七十三年前の記録の「最後の空白」を前に、テルが「問いがさらに深まった」状態で終わる。次を読ませる引き。

**登場人物**
テル（部分的にアルリックが廊下で一言だけ）

**場所**
作業室 → 廊下

**起きること**

- 夕方、シリアが呼ばれて戻る。テルは一人で記録の最後のページを読む
- 記録の最終行の手前に、一番大きな空白がある
  - 前後の行は読める: 「接続は、一度だけ成功した」という行と、「以降の記録はない」という行に挟まれた、大きな空白
  - 「一度だけ成功した」とは何に。「以降の記録はない」は、記録が終わったのか、記録できなくなったのか、それとも記録を消したのか
- テルが記録を閉じる。机に置く。窓の外がもう暗くなっている
- 廊下に出たところでアルリックとすれ違う
  - アルリックが立ち止まる。テルも立ち止まる
  - 「進んでいるか」と一言だけ聞く（記録の件か、ノード形式の件か、どちらを指しているか分からない問い）
  - 「……少し」とだけ答える
  - アルリックが頷いて、歩き去る。それだけ
- テルが廊下に一人になる
- 内部思考: 「接続は、一度だけ成功した」。その者が黒板で触れた先に、何があったのか。今、自分はその先を目指している。同じ場所に向かっているのか、それとも別の扉を開けようとしているのか
- 最後の一文: 手の中に、まだ記録の紙の感触があった（廊下の冷気・紙の感触という物理描写で終わる）

**伏線処理**
- F-35: 「接続は、一度だけ成功した」という記録の断片でもう一人の行動が一段具体化（進展）
- F-40: 「成功した接続の先に何があったか」という問いが宙吊りのまま章が終わる（引き）
- F-07: 七十三年前の者も同じ問いに立っていた、という照合がテルの内部にある

**Show, don't tellの注意点**
- 「謎は深まるばかりだ」「次が知りたくなった」という地の文は絶対に書かない
- テルが記録を机に「置く」という動作と、窓の外の暗さ、廊下の冷気だけで章末を作る
- アルリックの「進んでいるか」が記録の件かノードの件かあいまいなまま終わる。意図的な宙吊り

## 章末の状況

「接続は、一度だけ成功した」という記録の断片を手に入れたテルが、その先が空白であることを知ったまま廊下に一人で立っている。問いはひとつ増えた。答えはひとつも出ていない。

「次を読みたい」理由: 成功した接続の先に何があったのかが読者にも分からないまま終わる。シリアが「読めない」と言った行の正体も、テルには解釈できていない。二つの未解決が同時に宙吊りになっている。

## 七十三年前の記録の設計（プロットディレクター設計部分）

### 記録の構造

```
[読める行]  七十三年前、その者は黒板に触れた
[空白]
[読める行]  接続を試みた
[読める行]  失敗した
[空白]
[読める行]  別の経路を探した
[空白]
[読める行]  黒板は、古い書き方でなければ応答しない
[空白（インクの痕あり）]
[読める行]  接続は、一度だけ成功した
[大きな空白]
[読める行]  以降の記録はない
```

### 設計の意図

- 「空白の行」が最終章伏線（F-37：上位権限体系による消去？ / F-27：黙認慣例の起源？）への伏線として機能する
- 「古い書き方でなければ応答しない」がN-01（ノード形式不一致仮説）と直結し、七十三年前のもう一人がノード形式の問題を先に経験していたことを示唆する
- 「接続は、一度だけ成功した」は章末の引きであると同時に、F-35（もう一人の正体）・F-40（黒板に触れた意味）の次段階への問いを作る
- 「以降の記録はない」は意図的な宙吊り。「終わった」「消された」「消えた」「別の形式に移行した」のどれかは読者には判断できない
