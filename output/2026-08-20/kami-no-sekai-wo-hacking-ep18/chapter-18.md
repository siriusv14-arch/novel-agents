ep.18　第1章 第15話：起点（オリジン）―― 最初の問いを立てた者が、どこまで辿ったか

翌朝、イレーネさんが来た。

扉を叩いて、入らなかった。

「QY-001の照合記録は確認したか」

返事を待たなかった。

靴音が、廊下へ遠ざかっていった。

---

（……知っていた）

窓の外に、朝の光があった。まだ薄い。部屋の中は冷えていた。

QY-001の照合記録。昨夜、自分が問い合わせたのはQY-002だった。QY-001は、最初に返りを読んだ時に「移行ステータス: 継続中」「継承先: QY-007」を確認して、そこで手を止めていた。最後の行まで読んでいなかった。

QY-001に照合記録があることを、最初から知っている人の、訊き方だった。

（……この人は、どこまで知っている）

答えが出ないまま、立った。

---

昼、机に黒板を置いた。

昨夜のQY-002の返りを、頭の中で展開した。

「継承先: QY-003」

束の九枚目を思い出した。「――次は、」で止まっている。読点の後に、何もない。

「次は、」の先がQY-003のはずだった。あの人が書いていたのは、QY-001とQY-002の値だった。続けるとすれば、次は003だ。

```
> describe --target=NODE-07 --field=format_series --value-query=QY-003
```

間があった。昨夜と、同じ長さの間だった。

```
[format_series: 参照可 / マーカー照合による部分開示]
[QY-003: 第三規格 / QY-002の後継定義 / 移行ステータス: 完了]
[継承先: QY-004]
[照合記録: 0件]
```

一行ずつ、読んだ。

第三規格。QY-002の後継定義。移行ステータス、完了。継承先、QY-004。

最後の行で、指が止まった。

照合記録、0件。

（……誰も、来ていない）

あの人は「次は、」と書いて止まった。その先がここだった。QY-003に、誰も来ていない。あの人も、来ていない。来られなかったのかどうかは、書いていない。ただ、来ていなかった。

束の九枚目の「――次は、」の続きが、ここにあった。

---

イレーネさんの言葉を、もう一度、頭で展開した。

「QY-001の照合記録は確認したか」

昨夜、確認していなかった。最初にQY-001の返りを読んだ時も、「継続中」「継承先: QY-007」を確認して手を止めていた。照合記録の行を、読み飛ばしていた。

```
> describe --target=NODE-07 --field=format_series --value-query=QY-001
```

返った。

```
[format_series: 参照可 / マーカー照合による部分開示]
[QY-001: 初代規格 / 移行ステータス: 継続中]
[継承先: QY-007]
[照合記録: 2件 / 初回照合: 記録期限外 / 最終照合: 記録期限外]
```

2件。

昨夜のQY-002が1件だった。QY-001は、それより前から、2件ある。

初回照合、記録期限外。最終照合、記録期限外。

どちらも、日付が落ちている。いつ来たのかは分からない。それでも、2件、来た者がいる。

（……001に、二回）

QY-001には二回来た者がいる。QY-002には一回。

一人は001から002へ進んだ。もう一人は001だけで止まっている。

---

イレーネさんの執務室へ行った。

「報告があります」

扉の前に立ったまま言った。

「QY-001は2件でした。QY-002は1件、QY-003は0件です」

イレーネさんは羊皮紙に向かっていた。

手が、止まった。

「2件」

一拍、置いた。

繰り返したのではなかった。確かめる声だった。

「減っていく」

抑揚がなかった。断定だった。感情の色が、なかった。

「QY-004以降も確認するといい」

視線が羊皮紙に戻った。

廊下へ出た。

（……001から並べた）

001に2件、002に1件、003に0件。自分が頭の中で並べた順と、同じ順だった。同じ順で並べた人間が「減っていく」と言った。この構造を、最初から知っていた。

---

廊下の先で、術士が二人、立ち話をしていた。

通りすぎた。声が、後ろから追いかけてきた。

「また増えた。六回になった」

「いつから」

「今朝。昨日の夕方が五回だったんだ」

足を止めなかった。

（……五回から六回）

一日で一回増えた。前は数日かけて一回増えていた。縮まる速さが、速くなっている。

七十三年前の束の六枚目に、「信仰供給の乱れ回数」の増加記録があった。行の間隔が狭くなるくらい、後半は急いで書いていた。

今の術士たちが言っているのは、同じことだ。

---

机に戻った。

黒板の面を起こした。

「QY-004以降も確認するといい」という言葉が、まだ頭にあった。

```
> describe --target=NODE-07 --field=format_series --value-query=QY-004
```

```
[format_series: 参照可 / マーカー照合による部分開示]
[QY-004: 第四規格 / QY-003の後継定義 / 移行ステータス: 完了]
[継承先: QY-005]
[照合記録: 0件]
```

0件。

頭の中で、並べた。

001が最も多く、二件。002が一件。003以降は、ゼロだった。

起点に近いほど、多い。

（……そういう構造だ）

あの人は「次は、」で止まった。003が、止まった先だった。来る前に、何かが起きた。あるいは、来る理由がなくなった。

窓の外が、暗くなっていた。

昼が、夜になっていた。

（……次は、QY-005だ）

そこで止まった。

一拍、置いた。

（……続けていい）

黒板を、机の上に伏せた。

---

用語解説

起点（オリジン / origin）：「始まり」「最初に定められたもの」を指す言葉。バージョン管理ツールでは最初のソースリポジトリを「origin」と呼ぶ。どれだけ世代が変わっても起点への参照が保たれる設計は多く、「最初の仕様だけが今も継続中」というQY-001の状態も、起点が持つ特別な役割の一形態と言える。最初の問いを立てた者がどこまで辿ったかは、後続の照合記録の件数が語ることがある

参照カウント（reference count）：あるデータやリソースへのアクセス回数、または参照している箇所の数を数えた値。プログラム上でオブジェクトの生存管理に使われることが多く、カウントがゼロになったものは不要と判断される場合がある。この話の「照合記録」はその逆の視点として機能した。件数が多いほど多くの者が辿り着いた場所であり、ゼロは誰も来ていない場所を示した。QY-001の2件からQY-003の0件へと件数が落ちていく列は、起点から遠ざかるにつれて足跡が消えていく構造そのものだった
