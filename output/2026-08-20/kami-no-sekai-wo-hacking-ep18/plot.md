## シーン構成

### シーン1：翌朝 / イレーネの一言
**目的:** イレーネがQY-001の照合記録を知っていたことを示す。読者への情報提示ではなくテルへの衝撃として。

- テルが部屋で朝を迎えている（昨夜の余韻）
- イレーネが来る。立ち止まらずに言う
- 「QY-001の照合記録は確認したか」
- 問いではない。確認の口調
- それだけ言って去る
- テルの内省: 「QY-001に照合記録があることを、最初から知っていた人の訊き方だった」
- （……この人は、どこまで知っている）

**ポイント:** イレーネの台詞は一文のみ。余計な描写なし。テルの内省も短く。

---

### シーン2：昼 / QY-003を投げる
**目的:** 「――次は、」の続きを自分が辿ることの発見。

- テルが黒板の前に座っている
- 昨夜の束の九枚目を思い返す:「――次は、」
- QY-002の継承先がQY-003だった。「次は、」= QY-003のはず
- コマンド実行:

```
> describe --target=NODE-07 --field=format_series --value-query=QY-003
```

- 応答:

```
[format_series: 参照可 / マーカー照合による部分開示]
[QY-003: 第三規格 / QY-002の後継定義 / 移行ステータス: 完了]
[継承先: QY-004]
[照合記録: 0件]
```

- テルが読む: 「照合記録、0件」
- 内省: 誰も来ていない。あの人は「次は、」と書いた。その先が、ここだった。来られなかったのかは分からない。でも、来ていなかった
- （……0件）
- ここで止まる。QY-003は自分が初めて来た場所だ

**ポイント:** 「0件」の重みをテルの短い内省で見せる。説明しない。事実だけを積む。

---

### シーン3：QY-001を再投げ
**目的:** イレーネの一言を受けてQY-001の照合記録を確認。2件という発見。

- イレーネの「QY-001の照合記録は確認したか」を思い出す
- 昨夜、QY-002から始めた。QY-001は……最初に「初代規格」として見たが、照合記録は見ていなかった
- コマンド実行:

```
> describe --target=NODE-07 --field=format_series --value-query=QY-001
```

- 応答:

```
[format_series: 参照可 / マーカー照合による部分開示]
[QY-001: 初代規格 / 移行ステータス: 継続中]
[継承先: QY-007]
[照合記録: 2件 / 初回照合: 記録期限外 / 最終照合: 記録期限外]
```

- テルが読む: 2件
- 内省: QY-001には、二回来た者がいる。どちらも、記録期限外。システムが保っていられる範囲の外側
- QY-002が1件。QY-003が0件。QY-001が2件
- （……減っていくのか、増えているのか）
- 並べてみる: 001は2件、002は1件、003は0件
- 起点に近いほど多い。先へ行くほど、少なくなる

**ポイント:** ここでは「減っていく」という言葉をテルはまだ使わない。数字を並べて保留する。

---

### シーン4：イレーネへの報告
**目的:** イレーネの「2件」への反応を見せる。F-28（イレーネの調査動機）の進展。

- テルがイレーネに報告する
- 「QY-001は2件でした。QY-002は1件、QY-003は0件です」
- イレーネが「2件」で一拍、止まる
- 「減っていく」と言う。断定の声。感情は見えない
- 「QY-004以降も確認するといい」
- テルが内部で: 「この人は001から並べた。自分と同じ順序で」（→ イレーネも同じ問いの立て方をしている）
- テルが「QY-001の2件のうち、一件は昨夜自分がQY-002を照合した時のQY-001との差分……ではない。QY-001に来た者が二人、QY-002には一人しか来ていない。一人は001だけで止まった」と内部で言語化

**ポイント:** イレーネの台詞は短く断定的。感情を見せない。「2件」で止まった一拍だけが感情の痕跡。

---

### シーン5：廊下で「六回」（F-01進展）
**目的:** 不具合頻度の加速をさりげなく挿入。QY-照合の流れと並走させる。

- テルが廊下を歩いている（イレーネへの報告の前後どちらでも可。後がよい）
- 廊下の先で術士が二人すれ違っている
- 「また増えた。六回になった」
- 「いつから？」「今朝から。昨日の夕方が五回だったんだ」
- テルが足を止めない。ただ聞こえた
- 内部: 五回から六回。昨夜が五回で、今朝が六回。縮まる速さが上がっている
- （……早くなっている）

**ポイント:** 術士の声は一行か二行。テルは通過するだけ。内省は二行以内。

---

### シーン6：QY-004を投げる / 章末
**目的:** 「起点に近いほど多い、遠いほど誰も来ていない」という構造の発見。章末の許可。

- 「QY-004以降も確認するといい」というイレーネの言葉
- コマンド実行:

```
> describe --target=NODE-07 --field=format_series --value-query=QY-004
```

- 応答:

```

[QY-004: 第四規格 / QY-003の後継定義 / 移行ステータス: 完了]
[継承先: QY-005]
[照合記録: 0件]
```

- テルが並べる（頭の中で、または手元のメモとして）
  - QY-001: 2件
  - QY-002: 1件
  - QY-003: 0件
  - QY-004: 0件
- 内省: 起点に近いほど多い。遠いほど、誰も来ていない
- あの人は「次は、」と書いて止まった。止まった先が003だった。003も004も、来ていない
- 起点に近いから来た者がいた。先へ進んでいくほど、人が来なかった。そういう構造だ
- 「次はQY-005だ」と思う。そこで止まる
- 夜になっている
- （……続けていい）
- 章末

**ポイント:** 「続けていい」は自分自身への許可。疑問ではなく確認。次話への引きを作る。

## 用語解説（章末）
以下のいずれか1〜2個を自然に解説する:

**候補1: 起点（オリジン / origin）**
システム設計や記録の文脈で「どこから始まったか」を示す最初の参照点。バージョン管理では「origin」が最初のソース（発信元）を指す。どれだけ世代が変わっても、起点への参照は残り続ける設計が多い。

**候補2: 参照カウント（reference count / 照合件数）**
あるデータ・リソースに「誰が・何回アクセスしたか」を数えた値。ゼロの場合、そのリソースはまだ誰にも参照されていないことを示す。件数の多寡は重要度や知名度を反映することがあるが、「誰も来ていない場所」も存在することを示す値でもある。
