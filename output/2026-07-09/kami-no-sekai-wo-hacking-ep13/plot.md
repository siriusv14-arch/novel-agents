## 章タイトル案

**「届く（デリバー）―― 向こうが、選んで、送ってきた」**

## テーマ

「届く前の最後の調査、そして何かが届く」

テルが「外部定義」の源泉を辿る調査を深める（技術軸）と、シリアへの接触が断続的から継続的・強化に変わる（感知軸）が並走する章。
章末で「辿ろうとしている方向と、シリアに届いている方向が同じかもしれない」という収束の予感で閉じ、次章への推進力とする。

## シーン構成

### シーン1：翌朝 / テルの部屋 — 「外部定義」の源泉を辿る新しいアプローチ

**場所**: テルの部屋。机。灯りはもう要らない（朝の光）。
**登場人物**: テルのみ。

**流れ**:
1. 書き出し。テルが目覚め、黒板が机の上にあることを確認。昨夜の返り（`外部定義 / 参照元: 不明`）がまだ表示されている。
2. 「参照元が不明なら、別のフィールドから辿れるかもしれない」という思考整理。新しいアプローチの判断。
3. コマンド実行:
   ```
   > describe --target=NODE-07 --field=auth_source
   ```
4. 返り:
   ```
   [auth_source: 参照不可]
   [発行者: 未登録]
   [発行先: この定義のみ]
   ```
5. 「発行先: この定義のみ」という行で手が止まる。
   → 他の誰かのために同じ権限を発行したのではない。この権限は、自分のために、一つだけ、作られた。
   → F-07の一歩: 「（……誰かが、これを、僕のために設定した）」という内部認識。完全な答えは出ない。
6. F-37の進展: 「参照不可」は「存在しない」ではない。壁の性質が変わった——「ない」から「見えないが、ある」に。
7. F-42の接続: 「これが、形式から辿る、ということだ」という内部思考を一文入れる。
8. 次のアプローチを決める: 「格納先」を辿ること。イレーネに先に報告してから試みるか、試みてから報告するか迷い、報告を後回しにして動き始める。

**感情の温度**: 「知ってしまった」からの続き。焦りではなく「問いが精密になっていく」という静かな集中。前世で同じ種類の集中を知っている——あの時は間に合わなかった、という記憶が一瞬よぎる（F-02の保温にもなる一文）。

### シーン2：昼前 / 渡り廊下 — シリアの突発的感知変化

**場所**: 渡り廊下。本棟からシリアの部屋への通路。
**登場人物**: テル、シリア。

**流れ**:
1. テルが記録室へ向かおうとして渡り廊下を通ると、シリアが反対方向から来る。
2. シリアの様子: 歩いているが壁に手を触れている。顔色は普段より薄い。
3. テルが声をかける。「シリア、どうした。」
4. シリアの返答——感知の変化を断片的に語る:
   - 「……なんか、ずっと、来てる」（断続的→継続的に変化）
   - 「昨日の夕方から。ちょっとずつ、大きくなってる感じ」
   - 「押されてる、じゃなくて……なんか、ことばじゃないけど、たくさん来る。ずっと」
5. テルが確認のため黒板でpingを打つ → 黒板側: 「[応答あり / 信号微弱]」変化なし。
6. シリアは「黒板じゃないとこから、来てる。わかんない。でも……別の」と言う。
7. 新規-ep11-B確認: テルが内部で「向こうは黒板を通さない。引き続き、シリアに直接届けている。向こうが選んでいる。」と確信。
8. テルが「どっちから来てる?」と聞く。シリアが同じ方角を指す（新規-ep11-Aの確定: ep11と同じ方角）。
9. F-20の埋め込み: 「（向こうはシリアを、中継器として認識している。専用の、高性能な。それ以外に、この選択の意味がない）」という内部思考。
10. F-10の進展: 「（利用しようとしていたんじゃない。もう、利用し始めている）」という内部言語化。
11. 新規-ep13-Aの設置: 「ことばじゃないけど、たくさん来る」という証言を記録する描写。届いたものの内容が不明のまま。
12. 靄の描写: シリアの指先が微かに震えている。靄は出ていないが、テルが「長く続けさせてはいけない」と感じ、話を打ち切る。
13. シリアを部屋まで送り、戻す。

**感情の温度**: テルが「大丈夫だよ」と言えるかどうかの判断。ep11と同じ言葉を使うかもしれないが、今回は「それが本当かどうかが、前より分からなかった」という内省を入れる。一段階、緊張が増している。

---

### シーン3：夕方 / 記録室の前 / 廊下 — イレーネへの報告・F-28進展

**場所**: 廊下（記録室の近く）。定番の報告場所。
**登場人物**: テル、イレーネ。

**流れ**:
1. テルがイレーネを廊下で捕まえる。イレーネは羊皮紙を抱えていつもの姿。
2. テルが今日の二つを報告する:
   - 調査結果: `auth_source` が「発行者: 未登録 / 発行先: この定義のみ」を返した
   - シリアの変化: 断続的→継続的に強化。黒板を通さない経路で届いている
3. イレーネのシリアへの反応: 「来るべきものが来た」という顔。しかし今回は、ep11より重い——眉が動く、または羊皮紙を持つ指に力が入る、という細部描写。
4. イレーネのテルの調査報告への反応: 「発行先: この定義のみ」を聞いた時、一拍置く。「……それが出たの」と低く言う。
   → これはイレーネが「想定していたが、ここまで来るとは思っていなかった」という反応。
5. イレーネが短く言い置く: 「次は、格納先を問う方向で試してみて。発行したものがどこに入っているかを。」
   → テルが自力で考えていたことと一致。「（先を知っている。また、先を）」という内部思考。
6. F-28の進展: 「（なぜイレーネさんは、この問いの次にどこへ行くべきかを知っているのだろう。これは七十三年前の記録の調査ではない。もっと、近いところで、別の何かを知っている人間の案内の仕方だ）」という内部認識。F-44との連動: 「予測の精度が高すぎる。調査で得た情報だけでは、こうはならない。」
7. イレーネが歩き出す前に、一言だけ付け加える: 「シリアに届いているものの内容が、断片的にでも分かりそうなら、記録しておいて。何が来ているかより、どう届いているかを。」
   → この一言がF-28の「何かを知っている」という印象を一段深める。テルは問い返せない。

**感情の温度**: テルが「訊いてはいけない」と思う理由が、敬意から「恐れ」に変わりかけている。恐れではなく、「訊いた時に答えてくれる段階ではない、という確信」に近い。

---

### シーン4：夜 / テルの部屋 — 調査の継続と章末フック

**場所**: テルの部屋。机。灯り一つ。
**登場人物**: テルのみ。

**流れ**:
1. 夜、テルがイレーネの指示通り「格納先」を試みる。
2. コマンド実行:
   ```
   > describe --target=NODE-07 --field=auth_container
   ```
3. 返り:
   ```
   [auth_container: 外部参照]
   [格納先: NODE-07外部 / アドレス: 参照不可]
   [照合形式: 自動 / トリガー: 接続時]
   ```
4. 「照合形式: 自動 / トリガー: 接続時」という行が引っかかる。
   → 自動で、接続のたびに照合される。タイミングがある。これは「設計として、定期的に参照されている」ということ。
5. F-41との連動: 「（格納先が外にある。七十三年前の記録も、複数の場所に分けて残された。誰かが分散して置いた。同じ構造に、似ている）」という内部照合。
6. ここで黒板を閉じる前に、もう一度だけ同じ `trace` コマンドを打ってみる（F-43の継続確認）:
   ```
   > trace --target=NODE-07 --history=before
   ```
   → 前回5行だったが、今回は変化なし（5行のまま）。「向こうは、今夜は、動かなかった」という確認。
7. 黒板を閉じる。窓の外を見る。
8. **章末フック**: 「届く前に、とイレーネさんは言った。でも、シリアには、もう届いているのかもしれない。届く前、という時間の外に、シリアは一人でいる。」
   → 次章への推進力: 「辿りきれない前に、向こうが来る」という緊張の転換。

**感情の温度**: 焦りではない。「問いの地図が広がった分、自分がどこにいるかが見えにくくなった」という感覚。ただ、それでも打ち続けることしか、テルには知らない。

## 感情の山場

**シーン2（シリアの変化を受け取る場面)**

ep11の「大丈夫だよ」は「本当かどうかわからないが言った」。ep13では「前より分からなかった」。この一段の変化が今章の感情の核。「届く前に調査できるか」という問いが「届き始めているかもしれない」に変わる瞬間の、テルの静かな重さ。

## ライターへの追加指示

### 文体・テンポ
- テルの内部思考: 全角「（……）」を使用。ep10・ep12の文体を参照。
- 一文は短く。断定より推測・積み上げで。
- 黒板コマンドはコードブロック形式を維持（既存書式`--target=`、`--field=`、`--depth=`と整合）

### キャラクター別注意
- シリア: 文が短く、途中で終わる。「なんか」「〜みたいな」「〜感じ」。「……」始まり多用。
- イレーネ: 端的・断定的。「〜ね」「〜でしょう」「〜記録しておく」。余計な感情表現なし。
- テルのイレーネへの口調: 「〜です/ます」の丁寧語。

### 用語統一（ep13用）
- 「NODE-07」（QY-省略形定着）
- 「外部定義（external definition）」（ep12で確立）
- 「UNDEFINED」「RECORD_BOUNDARY」「auth_format」（ep12確立済み）
- 「auth_source」「auth_container」（ep13新登場コマンドフィールド）

### 禁止事項
- 「かくして」「〜なのであった」「輝かしき」等のAIっぽい文体
- イレーネが感情・前世について話す（第2章以降の信頼フェーズ）
- F-07の根本回答を出す（最終章回収）
- 「神が意図的に設定した」という方向へテルが踏み込む（示唆に留める）
