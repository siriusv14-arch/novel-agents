ep.13　第1章 第10話：届く（デリバー）―― 向こうが、選んで、送ってきた

目が覚めた時、三つの問いは、まだそのまま頭の中にあった。

昨夜、机に置いたまま眠ったらしい。黒板が、そこにあった。灯りは、もう要らなかった。窓から、朝の光が入っている。低くはない。まっすぐに、机の上を照らしていた。

その光の中で、黒板の返りが、まだ残っていた。

昨夜、閉じる前に打った手の、最後の一行。

```
[認証フォーマット: 外部定義 / 参照元: 不明]
```

その行を、もう一度、読んだ。

寝て起きても、消えていなかった。夢の中で片づいて、朝には別の形になっている、ということもなかった。参照元、不明。昨日と同じ言葉で、同じ場所に、残っていた。

起き上がって、机に向かった。

（……参照元が、不明）

不明、というのは、辿ろうとして辿れなかった、ということだ。訊いたけれど、返ってこなかった。だったら、訊き方が悪かったのかもしれない。同じ扉を、同じ叩き方で叩いても、開かない。開かないなら、別の場所を探す。

昨夜は、認証の「形式」を訊いた。外部定義、と返ってきた。形式は分かった。分からないのは、その形式が「どこから来たか」だ。

形式そのものではなく、その形式を「発行した元」を訊けばいい。

指を、コンソールに当てた。

```
> describe --target=NODE-07 --field=auth_source
```

返ってきた。

```
[auth_source: 参照不可]
[発行者: 未登録]
[発行先: この定義のみ]
```

三行目で、手が止まった。

発行先。この定義のみ。

一行目と二行目は、昨日までと、地続きだった。参照不可。未登録。訊いても答えがない、という壁のいつもの形。慣れてきた壁だ。またか、と思うだけの。

でも、三行目は、違った。

発行先が、この定義のみ。

（……この定義のみ）

権限というのは、ふつう、束で管理される。同じ形式で、何人にも配る。管理者が十人いれば、同じ発行元から、十の権限が出ている。発行元を辿れば、その十が、ぶら下がって出てくるはずだった。

でも、返ってきたのは、それ一つだった。

この発行元は、一つの権限しか、発行していない。僕の、この権限だけ。他の誰かのために、同じものを作った記録が、ない。

（……誰かが、これを、僕のためだけに、設定した）

流用ではなかった。余っていた権限を回してもらった、でもなかった。この権限は、一つだけ、作られている。宛先が、最初から、一人に決まっていた。

チョークを、握ったまま、動かせなかった。

root権限。ずっと、通ってきた。ep1から、当たり前みたいに通ってきた。何度も書き換えて、何度も直して、そのたびに黒板は僕を通した。昨夜、その理由の欠片を見た。外部定義。外から差し込まれている。

今朝、その欠片が、もう少し、こっちに近づいた。

外から差し込まれているだけじゃない。外から、僕のために、差し込まれている。

前世で、似た話を、一度だけ聞いた。権限を、外から贈られる。あなたの知らないところで、誰かがアクセス権を発行しておく。理論上は、あり得る。でも現実には、そんなことをする理由がない。冗談みたいな仮定だった。笑って流した。

流したはずの話の、その続きまで、目の前に来ていた。

しかも――発行先は、この定義のみ。理由がないどころか、その誰かは、僕一人のために、それをやっている。

（……参照不可、は、無い、じゃない）

そこは、間違えないようにした。参照不可。それは「存在しない」ではない。訊けない、というだけだ。壁の向こうに、発行元は、ある。ただ、こちらから覗く窓が、塞がれている。昨日までは、壁があるのかどうかも、はっきりしなかった。今は、壁があることは分かる。壁の形が、少しずつ、見えてきている。

――この先を知りたければ、形式から辿れ。

複写の書き足しが、戻ってきた。

（……これが、形式から辿る、ということだ）

昨夜、外部定義という形式に行き着いた。今朝、その形式の発行元へ、一歩進んだ。書き足しの言葉が指していたのは、たぶん、この手順のことだ。形式を読んで、形式の元を辿る。指示と、自分のやっていることが、ようやく、同じ形に重なった。

チョークを置いた。

朝の光が、机の上で、少しだけ角度を変えていた。

（……発行元が辿れないなら)

発行された、その先を辿ればいい。この権限が、今、どこに置かれているのか。発行元は塞がれていても、置き場所までは、見られるかもしれない。

コマンドの形は、頭の中にあった。打とうとして、指を止めた。

イレーネさんに、先に報告するか。それとも、試してから、報告するか。

少しだけ、迷った。昨日の報告は、もう済んでいる。次に会うのは、たぶん今日のどこかだ。それまで待って、指示を仰いでから打つのが、筋ではあった。

でも、待っている間に、黒板は冷める。今、手の中に、温度がある。

前世で、一度、待った。手順を踏んで、確認を取って、正しい順番で動こうとして。動いた時には、間に合わなかった。あの時の、手の中の温度を、覚えている。

指を、コンソールから離した。今度は、打たなかった。打つのは、夜でいい。日中に、確かめておくべきことが、別にあった。

シリアの様子を、見ていない。

黒板を懐にしまって、部屋を出た。

---

渡り廊下は、本棟からシリアの部屋へ抜ける、細い通路だった。

片側が壁で、片側が、腰の高さまで開いている。昼前の光が、その開いた側から、床に斜めの縞を落としていた。記録室へ回る前に、シリアの顔を見ておこう――そう思って通路に入った時、反対の端から、人影が来た。

シリアだった。

歩いていた。でも、いつもの歩き方では、なかった。片手を、壁に当てている。指先で、石をなぞるように。歩幅が、狭い。顔色が、いつもより薄かった。窓の光が当たっているせいではなく、内側から、色が引いている。

「シリア」

声をかけると、シリアが顔を上げた。目の焦点が、一拍、遅れて合った。

「……あ。テルさん」

「どうした。壁に、手」

「……なんか。まっすぐ、歩きにくくて」

壁から手を離そうとして、少しよろけて、また当てた。無理には離させなかった。

「気分が悪い?」

「……悪い、じゃないです。悪くはない。けど……」

言葉を、探していた。掴めないものを、掴もうとする、あの目だった。

「……ずっと、来てるんです」

「来てる?」

「昨日の、夕方くらいから。ちょっとずつ、大きくなってる、みたいな」

シリアが、壁から、ようやく手を離した。その手を、胸のあたりに当てる。何かが、そこから入ってくる、というふうに。

「前は……たまに、でした。来て、消えて、また来て。今は……消えない。ずっと、来てる。切れ目が、ない」

たまに、から、ずっと、へ。

断続していたものが、続いている。ep11で、シリアは「押し当てられる」と言った。何個かの方向から、押し当てられる、と。あの押し当てが、途切れなくなっている。

「押されてる、感じ?」

「……押されてる、じゃなくて」

シリアが、首を振った。うまく言えない、という振り方だった。

「なんか……ことばじゃ、ないんですけど。ことばじゃないのに、たくさん来る。ずっと、たくさん。……いっぱい、来てるのに、なんて言ってるか、わかんない」

言葉じゃない。でも、たくさん。

その言い方が、耳に残った。信号は、来ている。量がある。中身が、読めない。シリア自身にも、たぶん、僕にも。

念のため、確かめた。黒板を、懐から出す。深くは入れない。入り口だけ、軽く触れる。

```
> ping --target=NODE-07 --depth=surface
```

```
[応答あり / 信号微弱]
```

変わっていなかった。

昨夜、この目で見た返りと、同じ。信号微弱。僕の側は、静かなままだった。黒板には、何も、押し寄せていない。

なのに、シリアには、切れ目なく来ている。

（……黒板を、通していない)

僕が呼んだのでは、ない。僕の黒板を経由しても、いない。向こうは、黒板を飛ばして、シリアに、直接、届けている。ep11で一度、それを見た。あの時は、一回きりの接触に見えた。今は、続いている。

「テルさんの、それには」シリアが、黒板を見た。「来てない、ですよね」

「うん。こっちは、静かだよ」

「……やっぱり」

シリアが、少しだけ、笑おうとした。笑いきれなかった。

「わたしのとこ、だけ、なんだ」

その言い方に、何と返せばいいのか、すぐには出てこなかった。

（……向こうは、選んでいる)

昨夜まで、それは可能性だった。今、目の前で、事実になっている。向こうは、黒板を使わない。使えるのに、使わない。シリアを、選んでいる。何度でも、シリアを。

（……なぜ、シリアなんだ)

理由は、たぶん、一つしかなかった。シリアが、届く、からだ。黒板は、僕が読み解かないと、意味にならない。翻訳が要る。でも、シリアは、翻訳が要らない。信号を、そのまま、体で受ける。向こうにとって、シリアは、いちばん通りのいい経路だ。

（……向こうは、シリアを、器として見ている。専用の、通りのいい器として)

そうとしか、思えなかった。それ以外に、この選び方の理由がない。偶然、感染しただけの子ではなく、いちばん高い性能を持った、専用の受信機として、向こうはシリアを、識別している。

だとすれば――昔、聞いた話とも、繋がる。感染は、偶然だった。でも、向こうは後から、その偶然に気づいた。使えると、気づいた。

（……気づいて、利用しようとしていた。じゃない。もう、利用し始めている)

しようとしていた、では、なくなっていた。目の前で、続いている。切れ目なく。

「どっちから、来てる?」

訊いた。シリアが、開いた側の窓に、顔を向けた。手を持ち上げる。外の、一点を指した。

迷いのない指だった。

その方角を、頭の中の地図に、重ねた。

ep11で、シリアが指したのと、同じ方角だった。沿岸部の、先。恩恵の薄れる縁。その名前を、口に出したくない拠点のある方向。

心当たりは、ある。輪郭は、少しずつ、はっきりしてきている。まだ、確かめには行けない。でも、確かめるべきものが、方角として、動かなくなった。二度、同じ方向を指された。もう、偶然ではない。

シリアの、指した手が、微かに震えていた。

靄は、出ていなかった。黒いものは、どこにも滲んでいない。でも、この震えを、長く続けさせてはいけない、と思った。ep11で、僕は学んでいる。この子の感じる力は、いつも、代償と隣り合っている。強い受信は、あの黒いものを、また呼び起こしかねない。

「もういい。ありがとう」

黒板を、しまった。シリアの指が、ゆっくり下りた。

「部屋まで、送るよ。歩きにくいんだろ」

「……はい」

並んで、渡り廊下を戻った。シリアは、壁ではなく、僕の側に、少しだけ寄って歩いた。

部屋の前で、扉を開けてやった。シリアが、中に入る。振り返って、こちらを見た。

「……大丈夫、ですか。わたし」

ep11でも、僕は「大丈夫だよ」と言った。あの時、それが本当かどうか、自分でも分からなかった。分からないけれど、この子に必要なのは、その言葉だと思って、言った。

今も、同じ言葉が、口まで来た。

でも、前より、それが本当かどうかが、分からなかった。ep11の時は、少なくとも、接触は一回きりに見えた。今は、続いている。強くなっている。向こうは、この子を、手放す気がない。その中で「大丈夫」と言うことが、前より、重かった。

「……ちゃんと、見てるから」

出てきたのは、その言葉だった。大丈夫、とは、言い切らなかった。見ている、とだけ言った。それなら、嘘にならない。

シリアは、少しの間、僕を見て、それから、うなずいた。

「……はい」

扉を、閉めた。

閉めた扉の前で、しばらく、動けなかった。

（……ことばじゃないけど、たくさん来る）

さっきの言葉を、頭の中で、もう一度、置き直した。届いているものが、ある。量が、ある。でも、中身が読めない。それが、何なのか。何を、たくさん、送ってきているのか。

分からないまま、記録するしかなかった。分からない、ということも含めて。

---

夕方、記録室の前の廊下で、イレーネさんを捕まえた。

窓から、赤い光が入っていた。イレーネさんは、羊皮紙の束を腕に抱えて、こちらを見た。足を止める。

「二つ、ご報告があります」

「聞く」

「まず、シリアです」

イレーネさんの目が、羊皮紙から、上がった。

「感知が、変わっています。ep11では、複数方向から『押し当てられる』という状態でした。それが、断続的だったんです。来て、消えて、また来る。今日は――途切れていません。昨日の夕方から、ずっと続いていて、少しずつ、強くなっていると」

イレーネさんの、羊皮紙を抱えた指に、力が入るのが見えた。

「黒板は?」

「僕の側には、来ていません。pingを打っても、信号微弱のまま、変わりません。シリアにだけ、黒板を通さない経路で、届いています」

一拍、置いた。

「向こうは、黒板を使いません。使えるはずなのに、使わない。シリアを、選んでいます」

イレーネさんは、すぐには何も言わなかった。窓の外の、赤い光の方へ、目を向けた。ほんの一瞬。それから、視線を戻した。

「来るべきものが、来た」

低い声だった。ep11の時にも、似た顔を見た。でも、あの時より、重かった。眉のあたりが、わずかに動いていた。予想が、当たったことを喜ぶ顔ではなかった。当たってほしくなかったことが、当たった、という顔に、近かった。

「もう一つ、ご報告が」

僕は、続けた。

「昨日の『外部定義』の、続きです。認証の形式ではなく、その発行元を辿りました。auth_sourceを問いました」

「それで」

「発行者は、未登録でした。参照も、できません。ただ――発行先が、『この定義のみ』と返りました」

イレーネさんの足が、廊下の石の上で、動かなくなった。

一拍。いや、それより、少し長かった。羊皮紙を抱え直す音も、しなかった。ただ、止まっていた。

「……それが、出たの」

呟くように、言った。

僕の顔を見て言ったのではなかった。半分、自分に向けた言葉だった。それが、出た。想定は、していた。でも、こんなに早くそこまで来るとは、思っていなかった――そういう、置き方の言葉だった。

「発行先が、この定義のみ、というのは」僕は、訊いた。「何を、意味しますか」

イレーネさんは、答えなかった。

代わりに、別のことを言った。

「次は、格納先を問う方向で、試してみて」

「格納先」

「発行したものが、どこに入っているか。発行元が閉じているなら、発行された先を見る。置き場所には、置いた者の癖が、残る」

（……先を、知っている)

また、だった。僕が、部屋で、次はそれを試そうと決めていたことと、言葉が、重なった。イレーネさんは、僕がどこで詰まって、次にどこへ手を伸ばすべきかを、僕より先に、知っている。

昨日も、そうだった。外部定義が返ると、辿り方が合っていた、と言った。今日も、そうだ。

（……なぜ、この人は、いつも、次にどこへ行くべきかを知っているんだろう)

これは、七十三年前の記録を調べている人の、案内の仕方ではなかった。古い記録を読み解いてきた、というだけでは、ここまで先回りはできない。予測が、精密すぎる。調査で得られる情報だけでは、こうはならない。もっと近いところに、別の何かを知っている人間の、案内の仕方だった。

訊けば、答えるだろうか。

答えない気がした。それだけではなく――今は、答えてくれる段階ではない、という気がした。訊いてはいけない、という遠慮とは、少し違っていた。訊いたところで、返ってくるものがない、という確信に近かった。

だから、訊かなかった。

イレーネさんが、歩き出した。半歩、行きかけて、足が、緩んだ。こちらは向かないまま、羊皮紙の束を抱え直して、背中で、付け加えた。

「シリアに届いているものが、断片でも分かりそうなら、記録しておいて」

「はい」

「何が来ているか、より――どう届いているかを」

その一言が、耳に残った。

何が、ではなく、どう。中身ではなく、届き方を。まるで、届き方の方に、答えがあることを、知っているみたいな言い方だった。

問い返す間は、なかった。イレーネさんは、もう廊下を歩いていた。背筋を伸ばした、いつもの歩き方で、赤い光の中へ入っていった。

---

夜、机に灯りを一つ点けて、黒板を置いた。

昼のうちに、決めていた。イレーネさんの指示と、僕の考えは、同じ場所を指していた。格納先を、問う。

指を、コンソールに当てた。

```
> describe --target=NODE-07 --field=auth_container
```

返ってきた。

```
[auth_container: 外部参照]
[格納先: NODE-07外部 / アドレス: 参照不可]
[照合形式: 自動 / トリガー: 接続時]
```

灯りの、揺れる音が、聞こえた気がした。

そんなはずはない。灯りは音を立てない。ただ、部屋が静かで、自分がその静けさに気づいた、というだけだ。昨夜も、同じことを思った。

一行ずつ、読んだ。

格納先は、外部参照。NODE-07の、外にある。アドレスは、参照不可。ここまでは、想像がついた。発行元が外なら、置き場所も外だろう。慣れてきた壁の、いつもの形。

引っかかったのは、三行目だった。

照合形式、自動。トリガー、接続時。

（……自動)

僕の権限は、どこかに置いてある。そこまでは、分かっていた。でも、ただ置いてあるだけ、ではなかった。自動で、照合されている。しかも、接続のたびに。

僕が黒板に触れて、システムに繋がる。そのたびに、外に置かれた僕の権限が、自動で、照らし合わされている。誰かが、その都度、手で確認しているのではない。仕組みとして、そうなっている。接続のたびに、外の誰かが――何かが――僕の権限を、定期的に、参照している。

（……設計として、そうなっている)

置き忘れられた権限では、なかった。管理されている。僕がこの黒板に触れるたびに、外側で、何かが動いて、僕を照らし合わせている。それが、設計として、組み込まれている。

七十三年前の話が、頭の中に、重なった。

複写に書き足しをした、あの人物。あの人は、記録を、複数の場所に分けて残した。一つにまとめず、分散させて、置いた。誰かが探しても、簡単には辿れないように。あるいは、一つが失われても、残るように。

（……格納先が、外にあって、分散している)

僕の権限の置き方と、七十三年前の記録の置き方が、似ていた。中にまとめず、外に出して、辿れないようにする。同じ癖の、手つきに見えた。イレーネさんは、置き場所には置いた者の癖が残る、と言った。もし、この癖が、あの人物のものだとしたら――僕の権限を外に置いた誰かと、七十三年前の誰かが、繋がっているのかもしれない。

線を、引きたくなった。

引かなかった。まだ、引きたいから引く線だ。確かめる手段が、一つもない。

黒板を閉じる前に、もう一度だけ、昨夜と同じ手を打った。向こうが、動いていないかを、確かめるために。

```
> trace --target=NODE-07 --history=before
```

```
[ERROR: RECORD_BOUNDARY]
[no prior index accessible]
[最古層: NODE-07]
[参照可能なフォーマット仕様: 非公開 / 問い合わせ先: UNDEFINED]
[参照先フォーマット: 複数定義あり / インデックス: 参照不可]
```

五行だった。

昨夜と、同じ。増えていなかった。

（……今夜は、動かなかった)

向こうは、黒板の中では、静かにしていた。昨夜、四行から五行に増えた、あの変化は、今夜は無かった。黒板の側では、何も起きていない。

でも、それは、向こうが止まった、という意味では、なかった。

昼に、シリアが、壁に手を当てて歩いていた。ことばじゃないのに、たくさん来る、と言った。切れ目がない、と。黒板の中で静かにしている間、向こうは、別の場所で、動いていた。黒板ではないところで。シリアの、いるところで。

チョークを、置いた。黒板を、閉じた。すぐには、立たなかった。

窓の外を、見た。夜だった。方角は、闇に沈んで、見えなかった。でも、どっちに何があるかは、もう、体が覚えていた。

――こちらに、届く前に、辿れるといい。

イレーネさんは、そう言った。届く前に、と。まだ届いていない、その手前で、辿ってしまえ、と。時間が数えられている。向こうが来るまでの時間が。

でも。

（……シリアには、もう、届いているのかもしれない)

届く前に、という言い方は、僕たちのいる場所への話だった。聖務局へ、黒板へ、届く前に。でも、シリアは、その時計の、外にいた。僕たちに届くより先に、切れ目なく、受け取っている。

届く前、という時間の、その外側に、シリアが、一人で、いる。

まだ誰にも届いていないものを、あの子だけが、もう受け取っている。それを、たくさん、と呼びながら。なんて言ってるか、わかんない、と言いながら。

灯りを、消さなかった。

しばらく、点けたまま、窓の外の、見えない方角を、見ていた。

用語解説

auth_source（認証発行元）：本来は、あるシステムがユーザーの権限を確かめるとき、その権限が「どこで発行されたか」を指し示す情報のこと。権限というのは、たいてい、発行した元をきちんと記録しておく。あとから「この権限は正しいのか」を確かめるとき、発行元に問い合わせて、照らし合わせるためだ。発行元をたどれば、同じところから発行された他の権限も、束になって見えてくることが多い。この話でテルが auth_source を問うたところ、「発行者: 未登録」「発行先: この定義のみ」と返った。発行した者の記録がなく、なおかつ、その発行元は、テルの権限ただ一つしか発行していない、という意味になる。誰かが、彼一人のために、外から一つだけ権限を作った――その気配が、この返りから立ちのぼってくる

auth_container（認証格納先）：本来は、発行された権限や認証情報が「どこに保管されているか」を指す入れ物のこと。権限は、発行して終わりではなく、どこかに格納しておいて、必要なときに取り出して使う。この格納先を見れば、その権限が、システムの内側で管理されているのか、それとも外側に置かれているのかが分かる。発行元をたどれなくても、格納先の置き方には、それを置いた者のやり方――癖のようなもの――が残る。この話でテルが auth_container を問うと、「格納先: NODE-07外部」と返った。彼の権限は、神のシステムの外に置かれ、外から管理されている。発行元も、格納先も、どちらも「外」にある、ということが、ここで重なって見えてくる

自動照合（automatic lookup）：本来は、あらかじめ決めておいた条件が満たされたときに、システムが人の手を介さず、自動的に情報を照らし合わせる仕組みのこと。「トリガー」とは、その照合を引き起こすきっかけのことで、たとえば「接続したとき」「一定時間ごと」といったタイミングが設定される。この話でテルの権限の照合形式が「自動 / トリガー: 接続時」と返ったのは、彼が黒板に触れてシステムへ繋がるたびに、外に置かれた彼の権限が、自動で照らし合わされている、という意味になる。置き忘れられて眠っているのではなく、接続のたびに、外側の何かが動いて、彼を確認している。定期的に参照されている、ということは、その先に、参照している「何か」が、確かにある、ということでもある
