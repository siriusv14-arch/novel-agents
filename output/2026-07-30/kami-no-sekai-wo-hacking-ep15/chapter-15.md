ep.15　第1章 第12話：痕跡（トレース）―― 消えた記録に、形式だけが残る

朝、黒板を開いた。

昨夜の返りが、まだ、残っていた。

```
[relay_format: 参照範囲外]
[対象: このノードは送信側ではありません]
```

二行目を、もう一度、読んだ。

明るいところで読むと、少し、違って見えた。夜は、これが、扉に見えた。閉まっている扉。閉まっている、ということしか分からない板。朝は、標識に見えた。こっちじゃない、と書いてある、道端の、木の板。

（……送信側を、探す）

昨夜、決めたのは、そこまでだった。探す、と決めた。どうやって探すかは、決めていない。

チョークを、持った。

送信側は、外にいる。外は、広い。広い方から探すのは、無理だ。手元にあるものから、辿るしかない。手元にあるのは、受け取っている側だ。NODE-07は、受け取っている。受け取ったものが、どこかに、残っていれば――残っていれば、そこから、送ってきた側が、見える。

（……受け取ったものの、記録）

言い直した。（……受け取ったものの、記録が、あるか）

指を、コンソールに当てた。

```
> describe --target=NODE-07 --field=receive_log
```

返ってきた。

```
[receive_log: 揮発性]
[コンテンツ保存: なし / 受信完了後に廃棄]
```

読んで、うなずいた。

揮発性。受け取ったら、捨てる。読んで、消す。残さない。

（……予想の、範囲だ）

がっかりは、しなかった。むしろ、そうだろうな、と思った。残していたら、こんなに長く、誰にも見つからずに、動き続けていられない。捨てているから、辿られない。捨てる設計にした誰かは、辿られることを、考えている。

そこまで考えて、指が、止まった。

（……捨てているのは、中身だ）

前世で、障害の原因を追っていた時のことを、思い出した。本文が落ちたログを、何度も見た。保存期間を過ぎて、中身は、消えている。それでも、一行目だけが、残っていることがあった。いつ、どこから、どういう形で来たか。中身の代わりに、包み紙だけが、残っている。

包み紙から、送り主が分かることが、あった。

（……中身が消えても、形式が、残っていることが、ある）

中身は、揮発性だ。読んで、捨てられている。でも、受け取る時には、形式が要る。どういう形で来たものを、どう開けたか。開け方の記録が、残っていないか。

チョークを、握り直した。

```
> describe --target=NODE-07 --field=receive_format_trace
```

返ってきた。

```
[receive_format_trace: 参照可]
[形式マーカー: 検出済み]
[マーカープレフィックス: QY-]
```

一行目で、手が、止まった。

参照可。

（……参照、可）

読み返した。何度も、同じ形の返りを見てきた。参照不可。参照範囲外。未登録。UNDEFINED。壁の名前ばかりを、覚えた。

参照可、という三文字を、久しぶりに見た。

いつからか、返りを読む時、まず、壁の名前を探すようになっていた。どこで止められているかを、先に見る。見て、そうか、と思って、次の問いを考える。それが、手順になっていた。

壁があるのが、普通になっていた。普通になっていたことに、今、気づいた。

黒板の面に、指の腹を当てた。粉が、ついた。

二行目。形式マーカー、検出済み。中身は消えていた。でも、形式の印は、残っていた。捨てられていなかった。捨てる設計をした誰かは、中身は捨てたのに、印は、置いたままにしていた。置き忘れたのか、置く必要があったのか。

三行目を、読んだ。

マーカープレフィックス、QY-。

（……QY-）

顔を、上げた。

QY-NODE-07。ずっと、そう呼んでいた。会議でも、羊皮紙でも、頭の中でも。QY-NODE-07。最近は、短くして、NODE-07と書くことのほうが、多かった。QY-は、名前の、頭についているものだと思っていた。省略しても意味が通る、飾りのような、頭。

でも、今、返ってきたのは、名前では、なかった。

形式の、マーカーだ。受け取ったものの、形式に、QY-という頭が、ついていた。

（……名前と、形式に、同じ頭が、ついている）

チョークを、置いた。

置いてから、もう一度、三行目を、読んだ。

---

QY-NODE-01。QY-NODE-02。QY-NODE-03。

紙の上ではなく、頭の中で、並べた。七つ。01から07まで。

全部に、QY-が、ついている。違うのは、番号だけだ。

番号は、世代だ。会議で、僕が言ったことだった。01がいちばん古い世代で、07がいちばん新しい。世代が違えば、形式も違う。だから、01から06は、07と同じ呼び出し方では、返事をしない。沈黙していたんじゃない。合っていなかっただけだ。

（……世代が違えば、番号が変わる）

そこは、そうだ。番号は、変わる。

（……でも、QY-は、変わらない）

01も、07も、QY-だった。いちばん古い世代と、いちばん新しい世代で、頭が、同じだった。世代をまたいで、変わらないものが、そこに、一つ、ある。

世代が違っても変わらないものは、名前ではない。名前は、一つ一つのものにつく。世代をまたいで残るのは――系列だ。

（……QY-は、名前じゃない。系列だ）

指が、机の端を、押さえた。

系列、というのは、同じ設計から出たものの、まとまりだ。同じ考え方で作られたものは、細かいところが違っても、骨が、似ている。骨が似ているものには、同じ印をつける。後から見た人が、これは同じ流れのものだと、分かるように。

QY-という印が、ついている。ノードの名前にも。受け取ったものの、形式にも。

（……ということは）

息を、一つ、吐いた。

これまで、僕が追っていたのは、ノードだった。NODE-07。次はNODE-01。応答なしの六つ。一つずつ、番号を、追っていた。番号を追う、というのは、点を追うことだ。

でも、QY-が系列なら。追うべきものは、点ではない。

（……系列を、追える）

系列が分かれば、その系列に属するものの、形が分かる。形が分かれば、同じ系列で書かれたものは、読める。送信側が、同じ系列の形式で送っているとしたら――QY-系の形式を知っていれば、送信側の言葉も、読めるかもしれない。

そこまで、辿った。

辿って、止めた。送信側が同じ系列かどうかは、まだ、分からない。QY-系の形式で受け取っている、ということまでしか、返ってきていない。送っている側の頭が、同じかどうかは、書いていなかった。

（……でも、確かめる、順番があるとしたら）

まず、QY-という系列が、何なのかを、知ることだ。

指を、コンソールに当てた。

```
> describe --target=SYSTEM --field=format_series --query=QY
```

返ってきた。

```
[format_series[QY]: 参照不可]
[定義元: 外部 / アクセス権限不足]
```

参照不可。

（……壁だ）

慣れた形が、戻ってきた。二行目も、見慣れた並びだった。定義元、外部。アクセス権限不足。

五つ目の「外」だ、と数えかけて、やめた。これは、数えるものではなかった。外部定義。昨日、四つ目に数えたものと、同じ場所を指している。言い方が違うだけだ。同じものを二回数えて、増えたと思うのは、ただの、勘違いだ。

（……増えては、いない。同じ場所が、また、出てきただけだ）

でも、同じ場所が、また出てきた、ということには、意味があった。

僕の権限が、外で定義されている。QY-という系列も、外で定義されている。二つが、同じ言葉で、同じ壁の、向こうにある。並べたくなる。並べて、線を引きたくなる。

引きかけて、やめた。昨日と、同じだ。外という言葉が同じだから同じ場所だ、というのは、まだ、線ではない。

チョークを、置いた。

置いてから、一つ、気づいたことがあった。

今朝、参照可が、返った。receive_format_trace。形式の痕跡は、見えた。壁が、そこには、なかった。

（……見えた、ということは）

僕の権限が、そこまでは、届いたということだ。

これまで、権限は、いつも足りなかった。継承元。形式仕様。認証の発行元。同期の制御元。全部、届かなかった。届かないことに、慣れていた。

でも、今朝は、届いた。形式の痕跡までは、届いた。その一つ先――系列の定義には、届かない。

（……境目が、少し、見えた）

僕の権限で、どこまで見えて、どこから見えないのか。その線が、今朝、一本、引けた。壁があるのは、前から知っていた。壁がどこにあるかは、知らなかった。

なぜ僕にroot権限があるのか、という問いには、まだ、何も返ってきていない。でも、その権限で、何ができて、何ができないのかは、少しずつ、形になってきている。

（……できないことの形が、分かるのは、悪くない）

黒板を、閉じた。

午前は、そこまでだった。

---

午後、シリアの部屋へ行った。

渡り廊下の光は、朝や昼前とは、角度が違っていた。床に落ちた縞が、こちらの足元まで、伸びていた。歩くと、影が、縞を、横切った。

扉を、叩いた。

「……はい」

中に入ると、シリアは、寝台の縁に座っていた。窓の方を、向いている。膝の上ではなく、寝台の縁を、両手で、掴んでいた。座っているのに、掴んでいた。

「テルさん」

顔を、こちらに向けた。顔色は、昨日と、同じくらいだった。薄い。それ以上、薄くはなっていない。

椅子を、寄せて、座った。

「来てるの、続いてる?」

「……うん。ずっと」

「大きさは。昨日と、同じ?」

シリアが、少し、考えた。

「……同じ、だと思います。……慣れた、まま」

「急いでる感じは」

「……あります」

そこは、迷わなかった。

「……ずっと、急いでる」

膝の上で、指を、組んだ。量は、同じ。急いでいる、も、同じ。昨日から、動いていない。動いていないなら、記録することは、少ない。

そう思ったところで、シリアが、続けた。

「……でも、なんか」

窓の方を、見た。

「……前より、こっちから来てる、って、感じが、する」

「こっち、って」

シリアが、片手を、寝台の縁から離した。

指が、上がった。窓の外を、指した。

迷いは、なかった。手が、途中で、揺れなかった。指した先を、探してから指す、という動きではなかった。もう、そこにある、という指し方だった。

三度目だった。

（……同じ、方角だ）

前に、シリアが「何個か」と言った時は、こうではなかった。あっちと、あっちと、ちょっとずれたとこから、と言った。指も、一度、迷った。混ざっている、とも言った。二つか、三つ、と。

今日は、一本だった。

「前と、違う?」

訊いた。

「……前より、はっきり、した気がする」

シリアが、指を、下ろした。

「……前は、なんか……たくさんの中の、どれが、どれか、わかんなかった。……今は、こっちが、いちばん、って、わかる」

膝の上の、指が、動いた。

（……量は、変わっていない。急いでいるのも、変わっていない）

変わったのは、方角の、輪郭だった。にじんでいたものが、少しだけ、縁を持った。

（……近づいている、のか）

近づいているなら、はっきりする。それは、分かる。

でも、もう一つ、あった。シリアが、慣れてきた、と言っていた。受け取り続けて、聞き分けられるようになった、ということも、あり得る。同じものを何度も聞けば、どれが大きいかは、分かってくる。にじみが取れたのは、向こうが近づいたからではなく、こちらの、耳が、揃ってきたからかもしれない。

（……どっちなのかは、分からない）

分からないまま、書いておくことにした。方角の輪郭が、はっきりした。理由は、二つ考えられる。両方、書く。片方だけ書けば、片方を、忘れる。

シリアの手が、また、寝台の縁を、掴んだ。掴む、というより、置いていた。指の先に、力は、入っていなかった。

靄は、出ていなかった。どこにも、黒いものは、なかった。

窓の方を、見た。シリアが指した先を、確かめるためではなかった。そこに何かがある、ということを、この子が、毎日、体で、受け取り続けている。そのことを、考えた。

僕の黒板は、静かなままだ。何も、来ない。来ないから、僕は、記録が取れる。落ち着いて、可能性を二つ並べて、両方書いておこう、なんてことを、考えていられる。

考えていられるのは、届いていないからだ。

（……届いているのは、この子だけだ）

向こうは、この子を、選んでいる。選んだ理由は、たぶん、都合がいいからだ。よく届く。よく受け取る。器として、性能がいい。そういう目で、見られている。

そういう目で見られている子に、僕は、どう届いているか教えて、と訊いている。

（……同じことを、していないか）

手が、止まりかけた。

止まりかけて、続けた。訊くのを、やめたら、何も分からない。分からないままなら、この子は、ずっと、一人で受け取り続けることになる。訊くことと、使うことは、たぶん、紙一重だ。紙一重なら、どちら側に立っているかは、自分で、決め続けるしかない。

決め続けるためには、見ていないと、いけない。

「ありがとう。もう、いいよ」

椅子から、立った。

「……はい」

扉の方へ、行きかけた。

「あの」

振り返った。

シリアが、こちらを、見ていた。窓の方ではなく、こちらを、見ていた。

「……あそこに、なにか、あるんですか」

指を、上げなかった。上げないまま、訊いた。上げなくても、どこを言っているかは、分かった。

「……まだ、分からない」

答えた。分からない、というのは、本当だった。何かがある、とは思っている。それが何かは、知らない。知らないことを、知っているように言うのは、いちばん、してはいけないことだった。

「調べてる。分かったら、言う」

シリアが、うなずいた。

「……はい」

扉を、閉めた。

---

本棟へ戻る廊下で、二人の術士が、すれ違った。

「――また、縮まってる」

「今日は」

「四回」

足音が、後ろへ、抜けていった。

（……四回）

昨日は、三回だった。立ち止まらなかった。数字だけを、頭の中に、置いた。

---

夕方、記録室に入った。

棚が、天井まで並んでいる。羊皮紙の束が、背を揃えて、詰まっている。棚の間の通路は、二人がすれ違うには、狭い。

その通路の奥に、イレーネさんがいた。腕に抱えた束から、一冊ずつ、棚に戻している。

「ご報告があります」

「聞く」

手は、止めなかった。

「昨夜の続きです。送信側を探すために、受信の記録を、逆に辿れないかを、試しました」

「結果は」

「受信の記録は、揮発性でした。受け取った中身は、受信が終わった時点で、廃棄されています。残っていません」

イレーネさんが、一冊、棚に押し込んだ。

「それで」

「中身は残っていませんが、形式は、残っていました」

手が、止まった。

「形式」

「はい。受信の、形式の痕跡です。それを問いました。返りは――参照可でした」

イレーネさんが、こちらを、向いた。

腕には、まだ、束が残っている。それを抱えたまま、動かなかった。

「参照可」

「はい。形式マーカーが、検出済み、と返りました。マーカーのプレフィックスは――QY-です」

言葉が、そこで、一度、止まった。

イレーネさんが、抱えた束を、片手に、持ち替えた。

「QY-」

「はい。QY-NODE-07の、QY-と、同じです」

一拍、置いた。

「これまで、QY-は、ノードの名前の、頭だと思っていました。飾りのようなものだと。でも、受け取ったものの、形式にも、同じ頭がついています。ノードの名前にも、形式にも、同じ印がある、ということは――QY-は、名前ではなく、系列を、指しているのかもしれません」

「系列」

「同じ設計から出たものの、まとまり、という意味です。01から07まで、番号は違いますが、QY-は、全部、同じです。世代が違っても、変わらない。変わらないものは、一つ一つの名前ではなく、系統の側にあるものだと、思います」

イレーネさんは、何も言わなかった。

「もし、そうなら」

続けた。

「送信側も、同じ系列の形式を、使っている可能性があります。系列の定義が分かれば、送信側が、どういう形で送っているかも、辿れるかもしれません」

「定義は」

「訊きました」

首を、振った。

「参照不可でした。定義元は、外部です」

イレーネさんが、束を、棚に置いた。棚板の上に、寝かせるように置いて、指で、背を、揃えた。三冊の背が、一直線に、並んだ。

それだけだった。

（……読めない）

QY-という文字を、この人が前から知っていたのか、今、初めて聞いたのか。分からなかった。手が止まったのは、驚いたからかもしれない。話を聞くために、止めただけかもしれない。背を揃えたのは、考えていたからかもしれない。ただ、揃えたかっただけかもしれない。

いつもなら、何かが、返ってくる。それが出たの、とか。辿り方が合っていた、とか。今日は、それが、なかった。

返ってこないほうが、重いことがある。

答え合わせの言葉が出る時は、こちらの持ってきたものが、この人の予想の中に、収まっている。収まっているから、一言で足りる。今日は、その一言が、出なかった。

（……予想の、外に出たのか）

それとも、出したくない言葉のほうへ、話が、寄ったのか。

どちらなのかは、顔からは、出ていなかった。

「もう一つ、あります」

言った。

「昨夜、方法が二つある、と言われました。片方は、届いているものを、直接読む方向です。今日、そちらを動かしました。もう片方――七十三年前の、別の記録を探す方は、まだ、当てがありません」

イレーネさんが、棚から、手を離した。

「記録庫の地下を、確認したことは、ある?」

顔を、上げた。

「地下、ですか」

「七十三年前の、分類外の記録は、地上の棚には、置かれない」

こちらを、見ていなかった。棚の並びの、奥の方を、見ていた。

「分類できないものは、下に、送られる」

それだけ、言った。

そして、歩き出した。

棚の間の、狭い通路を、抜けていく。白い外套の裾が、棚の角を、一度、擦った。振り返らなかった。

訊く間は、なかった。地下のどこか、とか、入っていいのか、とか、なぜ知っているのか、とか。訊くべきことは、三つ以上あった。三つとも、間に合わなかった。

いつも、そうだった。

（……また、答えではなく、場所を、指した）

棚の間に、一人で、立っていた。

この人は、いつも、こうする。僕が詰まっているところの、次の一歩だけを、置いていく。二歩先は、置かない。詰まった、と言った次の日に、その一歩が、出てくる。まるで、僕がどこで詰まるかを、先に、知っているみたいに。

分類できないものは、下に送られる。

聖務局の慣例だ。そういう決まりがあるなら、知っている人は、いる。イレーネさんが知っていても、おかしくはない。おかしくはないけれど――今日、この話の流れで、それが出てくることは、また、少し、早すぎた。

（……訊けなかった）

訊いてもいい段階か、という話では、なかった。今日は、単純に、間に合わなかった。それだけだ。

棚の羊皮紙の背に、目を落とした。分類の記号が、並んでいる。全部に、記号がついている。ここにあるものは、全部、分類されたものだ。

分類されなかったものは、ここには、ない。

---

記録室を出て、廊下を、歩いた。

窓の外は、もう、赤くなかった。青が、灰色に、寄っていく時間だった。

歩きながら、三つ、並べた。

一つ。QY-という系列。形式の痕跡は、見えた。系列の定義は、外部にあって、届かない。

二つ。シリアの方角。三度、同じ方を、指した。輪郭が、はっきりしてきた。でも、そこへ行けば、黒板は、動かない。恩恵の届かないところで、道具を持たずに、何を話すのか。

三つ。記録庫の地下。分類されなかったものが、下に送られている。行けるかどうかは、分からない。新入りの写し係が、勝手に降りていい場所なのかも、分からない。

用語解説

receive_log（受信ログ）：本来は、システムが「何を、いつ、どこから受け取ったか」を書き残しておく記録のこと。障害が起きた時、いちばん最初に見る場所でもある。ただし、記録は際限なく増えるので、多くのシステムでは一定の期間や条件で捨てていく。中でも「揮発性」の受信は、受け取って処理した時点で内容を廃棄してしまうため、後から「何が来たのか」を確かめる術がない。この話でテルが receive_log を問うと、「揮発性 / 受信完了後に廃棄」と返った。内容は、残っていなかった。捨てる設計になっているものは、辿られないための設計であることも多い。誰かが「残さない」と決めたなら、その決めた誰かは、残ることの意味を、知っていたということになる

receive_format_trace（受信形式の痕跡）：本来は、受け取ったデータの「中身」ではなく、「どういう形式で受け取ったか」という枠組みの側の記録を指す。中身と形式は、別のところに書かれることがある。手紙の本文と封筒が別物であるように、本文を燃やしても封筒が残ることはあるし、封筒の宛名書きの様式から、どこから来たものかが分かることもある。この話では、受信した内容は揮発性で廃棄されていたにもかかわらず、形式マーカーの痕跡だけは残っていて、テルの問いに「参照可」と返った。これまでテルの黒板が返してきたのは「参照不可」「参照範囲外」「UNDEFINED」ばかりだった。中身が消えた後に、包み紙だけが残っている。技術の世界では、しばしば、その包み紙のほうが多くを語る

プレフィックス（prefix）：名前や識別子の先頭につく、決まった文字列のこと。単なる飾りではなく、「これはどの仲間か」を示す印として使われる。ファイル名の頭、コマンドの頭、識別番号の頭――先頭の数文字が揃っているだけで、そこに系統があることが分かる。この話で問題になったのは「QY-NODE-07」の「QY-」である。テルはこれを長らくノード名の一部、省略しても意味が通る頭だと思っていた。ところが、受信形式のマーカーにも同じ「QY-」がついていた。名前にも、形式にも、同じ印がある。番号は世代ごとに変わるのに、この頭だけは変わらない。世代をまたいで変わらないものは、個体の名前ではなく、系統の側に属している――そう考えた時、「QY-」の意味が、ひとつずれる

format_series（形式系列）：本来は、同じ設計思想・同じ仕様の系譜から生まれた複数の形式を、ひとまとめにして呼ぶための考え方。細部の作りが違っても、骨組みが同じであれば、同じ系列として扱われる。系列が分かるということは、その系列に属するものの「読み方」が分かるということだ。一つ一つを個別に解読しなくても、系統の作法を知っていれば、初めて見たものでも当たりがつく。点を追うのと、系統を追うのとでは、届く範囲が違う。この話でテルが「QY-」の系列定義を問うと、「参照不可 / 定義元: 外部 / アクセス権限不足」と返った。系列が存在するらしいことは分かった。その作法を書いた紙は、この世界の内側には、置かれていない
