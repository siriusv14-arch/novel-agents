ep.12　第1章 第9話：外部定義（エクスターナル）―― 形式は、どこから来たのか

廊下に、まだ立っていた。

イレーネが去ってから、どれくらい経ったのか分からない。黒板は、懐から出したまま、手の中にあった。打たなかった。打つ気になれなかった、というより、打つ前に確かめておきたいことが、頭の中で一つ、形になりかけていた。

窓の外の光は、さっきより低くなっている。赤い。ほとんど地面と水平に、廊下の石を照らしていた。

その光の来る方角を、もう一度、目で測った。

シリアが指したのと、同じ方角だ。

頭の中の地図を、そこに重ねた。聖都アルカナムは大陸の中央にある。ここから、光の落ちる方へまっすぐ辿れば――内陸を抜けて、沿岸部に出る。恩恵の薄れる縁だ。セルダ村よりも、さらに向こう。廃倉庫のあった一帯を越えて、海に近づいていく方向。

（……沿岸部の、先）

そこに何があるのかは、知っている。というより、聞いたことがある。神の術式が海水で減衰していく、その手前。魔道具が動かない集落が、いくつか。そして、その名前を口に出したくない拠点が。

確かめるには、ここを出るしかない。

でも、今じゃない。出て、辿り着いて、それで何が分かる。黒板は、恩恵の届かない場所では動かない。あの方角の奥へ行くほど、僕は自分の道具を失っていく。丸腰で歩いていって、指をさすことしかできないシリアと、同じになる。

（……先に、形式を理解する）

方角の先に何があるかを知るには、まず、向こうがどんな言葉で喋っているのかを知らなければならない。あの方角から来ている「複数の何か」。それが、どういう約束事で信号を送っているのか。

――この先を知りたければ、形式から辿れ。

複写の書き足しが、また戻ってきた。辿るべき形式は、NODE-07だけではない。イレーネも言った。NODE-07以外に、動いているものがある、と。

歩き出した。廊下の先、自分の部屋の方へ。

今夜、黒板を開く。

---

灯りを一つだけ点けて、机に黒板を置いた。

指をコンソールに当てる前に、少し迷った。何から打つか。答えは、決まっていた。まず、変わっていないかを確かめる。昨夜と同じ手を、もう一度。

```
> trace --target=NODE-07 --history=before
```

返ってきた。

```
[ERROR: RECORD_BOUNDARY]
[no prior index accessible]
[最古層: NODE-07]
[参照可能なフォーマット仕様: 非公開 / 問い合わせ先: UNDEFINED]
[参照先フォーマット: 複数定義あり / インデックス: 参照不可]
```

指が、止まった。

五行あった。昨夜は、四行だった。

（……また、増えてる）

一行、書き足されている。最後の行。参照先フォーマット、複数定義あり。

昨夜まで、向こうのフォーマットは「非公開」で止まっていた。仕様は見えない。それだけだった。でも今夜は、その先が付いている。仕様は見えないが、それが「複数ある」ということは、返してきた。

複数ある。

イレーネの言い方が、重なった。形式が一つしかないなら、そうは言わない――違う、そうは言っていない。でも、そういう意味のことを言った。NODE-07以外に、動いているものがある。形式は、一つではない。

（……複数あるなら)

別の言い方で呼べば、別のものが応える。理屈は、そうなる。ep9の会議で、僕はそれを言った。応答なしの六つは、沈黙していたんじゃない。フォーマットが合っていないだけだ、と。

試す。

NODE-07のプロトコルとは、別の書き方で。NODE-01を呼ぶ。番号だけ変えても、たぶん届かない。もっと古い、別の世代の書式で。

```
> ping --target=NODE-01 --protocol=legacy --depth=surface
```

```
[ERROR: PROTOCOL_UNDEFINED]
[legacy: 未定義のプロトコル形式]
```

（……legacyが、ない）

古い、という言葉そのものが、このシステムには無かった。

前に一度、同じ壁に当たっている。このシステムは、自分が何かを引き継いだ元の形式を、内部の語彙として持っていない。「古い」を指定しようとしても、「古いって何だ」と返してくる。引き継いだのに、引き継いだ記憶がない。あるいは、消してある。

手が、止まった。

複数ある、とは言う。でも、その複数のうちのどれか一つを名指ししようとすると、名指しする言葉がない。ドアはある、と教えてくれる。でも、ドアの名前は教えてくれない。

やめない。角度を、変える。

---

名前が分からないなら、名前を探すのをやめる。

そう考え直した。形式の名前を当てにいくんじゃない。その形式を「認識している何か」の方から辿る。NODE-07は、複数の形式を参照できる。だったら、NODE-07自身が、僕を何の権限で認識しているのか。それを訊けばいい。

指を、当てた。

```
> describe --target=NODE-07 --field=auth_format
```

返ってきた。

```
[auth_format: 外部定義]
[認証フォーマット: 外部定義 / 参照元: 不明]
[権限照合: root / 照合元: UNDEFINED]
```

灯りの音が、聞こえた気がした。

そんなはずはない。灯りは音を立てない。ただ、部屋が静かすぎて、自分がその静けさに気づいた、というだけだ。

外部定義。

（……外部）

もう一度、行を読んだ。認証フォーマット、外部定義。参照元、不明。

NODE-07が僕を認証している、その形式は――このシステムの内側で作られたものではない。外で定義されている。神のシステムの、外側で。

root権限。ずっと、通ってきた。ep1から、ep2から、当たり前みたいに通ってきた。何度も書き換えて、何度も直して、そのたびに黒板は僕を通した。なぜ通るのか、考えなかったわけじゃない。考えて、後回しにしてきた。通るなら、それでいい、と。壁に当たる日まで。

壁に当たった。ep9で、初めて。RECORD_BOUNDARY。通れないものが、出てきた。

通れないものが出てきて、はじめて、通るものの方が不思議に見えてきた。

そして今夜、その理由の欠片みたいなものが、返ってきた。

外部定義。

（……誰かが、外から、これを設定した）

僕のroot権限は、神が内側で与えたものじゃない。神のシステムの外で定義されて、外から差し込まれている。照合元、UNDEFINED。問い合わせ先も、たぶんない。誰が設定したのかを訊こうとしても、その宛先が、どこにも登録されていない。

壁の向こうに、何かが設計として存在している。それは、前から薄々思っていた。でも今夜のは、それより一歩、こっちに近い。壁の向こうにあるものが、僕自身を作っている。僕がここに立って、システムに触れられること、そのものが、向こうから来ている。

前世で、似た話を、一度だけ聞いたことがある。

権限を、外から贈られる。誰かが、あなたの知らないところで、あなたのアクセス権を発行しておく。理論上は、あり得る。でも現実には、そんなことをする理由がない。冗談みたいな仮定だった。笑って流した。

流したはずの話が、目の前で、行になっている。

チョークを、置いた。

黒板を、閉じた。すぐには、立たなかった。机の上に、灯りだけが残っている。

不安、とは違った。興奮でも、なかった。

（……知ってしまった)

それに近い。開けなくていい扉を、指で押してしまって、開いた、という感覚だった。

用語解説

外部定義（external definition）：本来は、あるプログラムやシステムが使う設定・権限・関数などを、そのシステム自身の内部ではなく、外側のファイルや別のシステムで定義しておくやり方のこと。内部にベタ書きせず外に出しておくことで、後から差し替えたり、複数のシステムで共有したりできる。便利な反面、「その定義が一体どこから来ているのか」を辿れなくなると、システムは自分がなぜその設定で動いているのかを説明できなくなる。この話でテルのroot権限に「外部定義」と返ったのは、彼の権限が神のシステムの内側で与えられたものではなく、外から差し込まれている、という意味になる。誰が、いつ、どこで定義したのか――その参照元が「不明」であることが、彼の存在そのものへの問いに変わっていく

プロトコル（protocol）：本来は、機械と機械が通信するときの「約束事」のこと。どんな順番で、どんな形式で信号をやり取りするか、を互いに取り決めておく。同じ言葉を喋る相手同士でなければ会話が成立しないのと同じで、プロトコルが合っていない相手には、いくら信号を送っても届かない。この話でテルがNODE-01を legacy（古い形式）というプロトコルで呼ぼうとして PROTOCOL_UNDEFINED（未定義のプロトコル）と返されたのは、「古い形式」という約束事そのものがシステムの語彙に存在しなかったからである。相手はそこにいる。でも、話しかける言葉が分からない。それが、今のテルの壁である

UNDEFINED（未定義）：本来は、プログラムの中で、値や参照先がまだ決まっていない・存在しない状態を指す。変数に何も入っていない、指し示す先が空っぽ、という状態で、そこを頼りに処理を進めようとすると多くの場合エラーになる。この話で「照合元: UNDEFINED」「問い合わせ先: UNDEFINED」と繰り返し返るのは、テルが「では、この権限は誰に問い合わせれば分かるのか」と辿ろうとしても、その宛先自体がどこにも登録されていない、という意味になる。答えが「無い」のではなく、答えを訊く相手すら「定義されていない」。空白が、そのまま返ってくる
