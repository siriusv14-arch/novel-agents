## 構成案（5シーン構成）

### シーン1：廊下の続き ── 心当たりを、地図に重ねる（全体の約15%）

**設定**：ep11の直後。夕暮れの廊下。テルが黒板を手に持ったまま一人で立っている。窓の外に夕の光。

**目的**：
- 新規-ep11-Aの処理：「心当たり」の正体を内部で言語化する（冒頭で必ず処理）
- ep11の章末フックへの回答を早期に出す

**描写のポイント**：
- 書き出しパターン：ep11直後の廊下から。黒板を手に持ったまま、テルがまだそこに立っている。光が動く描写ではなく「まだここにいる」という静止した状態から始まる（ep8〜ep11と異なるパターン：時間の移行ではなく、静止した状態への着目）
- テルが夕の光の方角を目で追う。頭の中の地図に重ねる
- 「心当たり」の内部言語化：
  - 「大陸の沿岸部の方角だ。セルダ村のさらに先。廃倉庫のあった一帯から、もっと外縁へ向かう方向」
  - 行動には移さない。「確かめるためには、ここを出なければならない。今は、それをする時ではない」
  - 代わりに：「ここで、別の辿り方をする。あの方角に何があるかを調べるには、まず形式を理解しなければならない」という方針が静かに固まる
- 新規-ep11-B（保温）：「向こうはシリアを選んだ。あの方角から。これが偶然なら、何も言えない。偶然ではないなら、向こうには何かを選ぶための仕組みがある」
- テルが廊下を歩き始める。今夜、黒板を開く

**示すべきこと**：
- 「心当たり」はZeroDayの活動圏に近い大陸沿岸部の方角であるという認識（確定はさせないが輪郭は明示する）
- 行動の優先順位の設定：「まず形式を理解する」という方針
- F-10の動機として機能：「ZeroDayがシリアを選んだなら、あの方角とシリアには繋がりがある」

**文体メモ**：
- このシーンは短くていい。内省の密度を上げる
- 地図の情報は「頭の中の地図」として処理。視覚的な地図を出さない
- 「確かめない」という抑制が行動に見える（廊下を歩き始める動作で締める）

### シーン2：夜の黒板（前半） ── 同じ問いを、別の形で（全体の約20%）

**設定**：当夜。テルの部屋。机の上に黒板。

**目的**：
- F-43の再確認：ep10・ep11で変化してきた応答が今夜はどうなっているかを確認
- F-42の始動：「形式を辿る」具体的な試み（角度を変える）
- NODE-01〜06への別フォーマットアクセスという調査方針の設定（N-01）

**描写のポイント**：
- まず確認のため、ep10と同一コマンドを打つ（F-43）

```
> trace --target=NODE-07 --history=before
```

- 返ってきた応答：
```
[ERROR: RECORD_BOUNDARY]
[no prior index accessible]
[最古層: NODE-07]
[参照可能なフォーマット仕様: 非公開 / 問い合わせ先: UNDEFINED]
[参照先フォーマット: 複数定義あり / インデックス: 参照不可]
```

  - 今夜は5行目が加わっている（ep10は4行目まで）
  - 「複数定義あり」──向こうには複数のフォーマットが存在する。イレーネの言っていた「形式が一つということはない」という言い方が重なる
  - 「複数定義あり」が返ったなら、別のフォーマットにアクセスする経路が「ある」という意味だとテルが解釈する

- NODE-07以外のノードへのアクセスを別形式で試みる（F-42・N-01）：
  - ep9でテルが会議で提起した「呼び出しフォーマットが合っていないだけで、向こうはずっとそこにいる可能性」を今こそ試みる
  - NODE-07のプロトコルとは別の書き方でNODE-01へのpingを試みる
  - 具体的には：NODE-07の接続形式（`NW://QY-NODE-07.ARK`）の「07」の部分だけを変えるのではなく、プロトコル自体を変えた書き方を試みる

- 別フォーマットの試行：

```
> ping --target=NODE-01 --protocol=legacy --depth=surface
```

```
[ERROR: PROTOCOL_UNDEFINED]
[legacy: 未定義のプロトコル形式]
```

  - 「legacy（古い形式）」という概念が、このシステムにはない（ep10の「古い形式という言葉すらない」という認識と同じ壁）
  - F-34（一行）：「このシステムに『古い』という概念がない。引き継いだ元の形式を、このシステムは自分の内部語彙として持っていない」
  - 手詰まり。でもやめない。

**示すべきこと**：
- F-43の進展：5行目「複数定義あり」が加わり、向こうは変化し続けている
- F-42の始動確認：別形式でのアクセスを試み始めたが、まだ「形式の言葉」が分からない
- N-01との連動：NODE-01へのアクセスを試みるという方針の設定
- F-34（任意）：古い形式の語彙がシステムに存在しない、という既知の壁の再確認

**文体メモ**：
- コマンドは2行まで。返ってくるエラーの方に比重
- テルの内省で「詰まる」描写。でも「また別の角度を探す」という粘り強さ

### シーン3：夜の黒板（後半） ── 権限の、来た場所（全体の約25%）

**設定**：同夜。シーン2に続く。テルが別の角度を試みる。

**目的**：
- F-07（赤警告）への最重要進展：root権限認証に「外部定義」という行が初めて返る
- F-42の具体的な別角度：プロトコル名ではなく「NODE-07の認証方式」から辿る試み
- 感情の山場：「自分の権限は神のシステムの外から来ている可能性がある」という静かな衝撃

**描写のポイント**：
- 角度を変える：「形式の名前を探す」のではなく「形式を認識している何か」を名指しする
  - NODE-07が「複数の形式を参照できる」なら、そのうちの一つをNODE-07経由で呼び出せないか
  - NODE-07の認証方式を照合する：NODE-07はどの権限体系でテルを認識しているのか

```
> describe --target=NODE-07 --field=auth_format
```

```
[auth_format: 外部定義]
[認証フォーマット: 外部定義 / 参照元: 不明]
[権限照合: root / 照合元: UNDEFINED]
```

  - 止まる。「外部定義」。
  - NODE-07の認証フォーマットは、このシステムの内側で定義されたものではない
  - 「外から定義された」権限でテルは認証されている。神のシステムの外から、誰かが、この権限を設定した
  - F-07の言語化：「なぜroot権限が通るのか、ずっと後回しにしてきた。でも今初めて、その答えの欠片に触れた気がする。外部定義。これは、神のシステムが内部で与えた権限ではない。外から来ている」
  - F-37（任意）：「壁の向こうが設計として存在する。そして、自分の権限そのものも、向こうから来ているのかもしれない」
  - 答えは出ない。「参照元: 不明 / 照合元: UNDEFINED」。でも、問いの形が変わった

- テルが黒板を閉じる。頭が、整理しきれていない

**今章の感情の山場**：
- 「外部定義」という三文字が返ってきた瞬間
- テルが「自分のroot権限は、神が与えたものではないかもしれない。誰かが外から、僕にこれを設定した」という可能性に初めて直面する
- Show, don't tell：テルが黒板を閉じて、机の上に置く。すぐには立ち上がらない。灯りだけが机の上に残っている
- 不安でも興奮でもない。「……知ってしまった、という感覚」

**示すべきこと**：
- F-07への手応え：答えは出ないが「外部定義」という事実が初めて示される
- F-42の進展：「形式を辿る」ことで、自分の権限の源泉に初めて触れた
- 新規-ep11-B（保温）：「向こうがシリアを選んだ。向こうが自分の権限を定義した。向こうは、複数の方向に意図を持って動いている」

**文体メモ**：
- コードは短く（3行以内）。感情の山場は内省の密度で表現
- 「外部定義」という語を見た後のテルの沈黙を丁寧に描く
- 前世の記憶との接続は一行まで（「前世で、これに似た経験があった。ルートを誰かに贈られた、という話を一度だけ聞いたことがあった。理論上の話だった。現実にはあり得ない、と思っていた」程度）

### シーン4：翌日 イレーネへの接触 ── 「分かっていた、という話」（全体の約25%）

**設定**：翌日の昼過ぎ。記録室の前の廊下。テルがイレーネを捕まえる。

**目的**：
- F-44・F-28の進展：イレーネとのやり取り一場面で両方動かす
- 「NODE-07以外に動いているもの」という昨日のイレーネの言葉への続き
- イレーネが「分かっていた」ということの重さをテルが改めて意識する
- 章末の引きへの橋渡し

**描写のポイント**：
- テルがイレーネに「昨日仰っていたことです」と切り出す
- 今夜の調査の報告：「NODE-07以外の別フォーマットでのアクセスを試みました。直接は通りませんでしたが、NODE-07の認証に関して——」
- 「外部定義という返し方をしました」と伝える

- イレーネの反応：足を止める。こちらを見る。「外部定義、ね」。
  - 驚かない。でも、今回は「来るべきものが来た」という顔ではなく、微妙に異なる何かがある
  - 「それが出たなら、辿り方が合っていたということよ」

- テルの内部（F-44進展）：「（……なぜ分かるのか。昨日もそうだった。シリアの感知変化もそうだった。イレーネさんは、いつも一歩先を見ている）」

- テルが「形式が複数ある、という可能性についても、ご存知でしたか」と聞く
- イレーネ：「複数ある。それは分かっていた、という話よ」 と端的に答える。「どれが動いているかは、分からなかった。でも今は」
  - 「今は、一つが動き始めている、ということが分かった。あなたのおかげで」
  - それだけ言って、歩き出す

- テルの内部（F-28進展）：「（……分かっていた。なぜ、分かっていたのか。このひとは、この件について何かを知っている。調査まで、というバルナバス様の命令の外で、行動している。その理由が、まだ分からない。でも、聞けない。聞くべきかどうかが、決まっていないから）」

- 去り際に、イレーネが振り返る（半歩だけ）：「NODE-07以外の動き。それがこちらに届く前に、辿れるといい」
  - 問い返す間がない。イレーネはもう歩いている

**示すべきこと**：
- F-44の進展：「なぜイレーネは予測できたのか」という問いが内部で強まる
- F-28の進展：「このひとは調査の外で行動している、その理由がまだ分からない」という認識の維持と強化
- 新規-ep11-B（間接）：「形式が複数ある、それは分かっていた」というイレーネの言葉が「向こうにも選択肢があった」という読みと重なる

**文体メモ**：
- イレーネの台詞は最小限に。情報を全部渡さない
- テルの内部は全角括弧「（……）」で。長くせず、問いの形で置く
- 記録室の前の廊下という場所設定を一行で描写する（ep11と同じ廊下だが、今回は昼の光）

### シーン5：章末 ── 辿る先が、複数ある（全体の約15%）

**設定**：廊下に一人。イレーネが去った後。

**目的**：
- 「形式は複数ある」「心当たりの方角（沿岸部の先）」「外部定義された権限」の三つが静かに重なる
- 次を読まずにいられない状態で閉じる
- 解決ではなく「調査の軸が具体化した」という緊張感

**描写のポイント**：
- テルが廊下に一人残る
- 頭の中で三つが重なる：
  1. 「形式から辿れ」── 形式は複数ある。NODE-07だけでなく
  2. 「シリアが指した方角」── 沿岸部の先。あの方向に何かが動いている
  3. 「外部定義された権限」── 自分のroot権限は外から来た。誰かが、設定した
- 「これら三つは、別々のことではないかもしれない。形式を辿れば、方角が出る。方角の先に、権限の出所があるかもしれない」という推論が浮かぶ。でも、確かめる手段がまだない
- 黒板を取り出す。すぐには打たない。持ったまま、廊下の先を見る

**章末の一文（候補）**：
「形式は、複数ある。辿る先も、一つではない。それだけは、今夜、初めて確かになった。」

あるいは：「外部定義。その三文字が、まだ胸の奥にある。誰かが、この権限を作った。それは、七十三年前より前のことかもしれなかった。」

**示すべきこと**：
- 次章への方向性：「別フォーマットでのアクセス方法を探し続ける」 + 「沿岸部の方角への調査は将来の課題」
- 解決はなし。「問いの形が、具体的になった」という状態で閉じる
- 読者が「次、どうなるのか」を明確に感じられる締め方

**章末の条件（次を読みたい状態）**：
- 「外部定義」の謎（誰が設定したのか・いつ設定されたのか）
- 「形式は複数ある」という事実（どの形式で辿るのか）
- 「沿岸部の先への心当たり」（次章でどう動くのか）
三つが未解決のまま、それぞれが読者の次を引っ張る状態
