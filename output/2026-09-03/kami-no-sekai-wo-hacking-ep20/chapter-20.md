ep.20　第1章 第17話：上流（アップストリーム）―― 届いているものには、源がある

朝、黒板の面を起こした。

打つ言葉が、決まっていなかった。

昨夜の問いは残っている。誰が、001を続かせている。問いの形はあるのに、それを黒板に渡せる形にできない。誰、という語を受け取るフィールドを、僕は知らない。

指を、置いた。

（……送っている側を、何と呼ぶ）

分からないまま、一つ目を打った。

```
> describe --target=NODE-07 --field=transmit_source
```

```
[transmit_source: 該当なし]
[このノードは受信側です]
```

短かった。

二つ目。

```
> describe --target=NODE-07 --field=upstream_node
```

```
[upstream_node: 参照不可]
[上流への問い合わせは、このノードからは実行できません]
```

三つ目。

```
> describe --target=NODE-07 --field=origin_node
```

```
[origin_node: 参照不可]
[問い合わせの向きが、定義に含まれていません]
```

三回、断られた。

断り方が、三回とも違った。

指を離して、頭の中に並べ直した。該当なし。実行できません。定義に含まれていません。

これまで壁に当たった時は、たいてい同じ言葉が返ってきた。アクセス権限不足。継承元、非公開。上に何かがあって、そこまで手が届かない、という断られ方だった。

今朝のは、違う。

（……権限の話じゃない）

向きの話だった。

受け取る口に、送り主の名前は書かれていない。書かれていないのではなく、書く場所が最初からない。そういう作りのものを、僕は毎日、外から叩いている。

前世で、似たことをした夜がある。届いた側の記録だけを見て、送り主を割り出そうとした。あの時は、送信元の欄そのものはあった。あっただけで、中身は途中で書き換えられる値だった。

ここには、欄がない。

（……逆からは、辿れない）

辿れないなら、外から回るしかない。

---

階段の下り口で、術士が二人、壁際に立っていた。

「八回だ」

「今朝からか」

「昨日の夕方が七回だった」

足は止めなかった。

（……七回から、八回）

また一日で、一回増えている。数え始めた頃は、数日かけて一つ増えるものだった。

地下の束の、六枚目を思い出した。後ろへ行くほど行の間隔が狭くなっていた、あのページ。あの人も同じ速さに追われながら、あの数字を並べていたことになる。

窓の外は晴れていた。

---

午後、シリアの部屋へ行った。

扉を叩くと、返事より先に、椅子の動く音がした。

「……テルさん」

寝台ではなく、窓の下の椅子に座っていた。顔色は、この前と同じくらいだった。それ以上、薄くはなっていない。

椅子を寄せて、座った。

「来てるのは、続いてる?」

「……はい。ずっと」

「大きさは」

「……同じ、だと思います」

「急いでる感じは」

「……あります」

そこは、この前も、迷わなかった。

「……ずっと、急いでます」

膝の上で、指を組んだ。ここまでは、前と同じだ。

「それで、あと――」

「……方角、ですよね」

先に言われた。シリアの手が、もう上がっていた。

窓の外を指した。同じ向きだった。四度目になる。

（……変わっていない）

「前と、違うところは」

シリアが、少し黙った。指は下ろさないままだった。

「……なんか」

指の先が、わずかに動いた。押すような動きだった。

「……近くなってる、感じ、が、します」

「近い」

「……はい」

「大きさは、同じなのに」

「……大きさは、同じです。……でも、遠くない」

言葉を探して、探しきれずに止めた、という止まり方だった。

指を組み直した。大きさと距離が、この子の中で別々に数えられている。混ざっていないなら、これは同じことの言い換えではない。

（……近い、というのは、何が近い）

向こうが動いているのか、届き方のほうが変わったのか。二つ並べて、両方書いておくことにした。片方だけ書けば、片方を忘れる。

「ありがとう。助かった」

「……はい」

立って、扉の方へ行きかけた。

窓の外に、午後の光があった。シリアが指した先は、その光より少しだけ左だった。

今朝、黒板は三回とも断ってきた。上流は見えない、と。

この部屋では、毎日、届いている。

（……黒板には届かない。この子には、届いている）

足が、止まった。

同じものを探している。片方は構造の外に立っていて、片方は毎日それを体で浴びている。

これまで、黒板とこの部屋は別の調査だった。黒板で形式を辿り、この部屋で感知を記録する。二本の列を、別々の紙に書いていた。

別々ではなかった。

上流は、この窓の外にある。

扉を閉めた。閉めてから、廊下でもう一度、同じ方角を確かめた。

---

本棟の廊下で、イレーネさんとすれ違った。

すれ違ってから、呼び止められた。

「進んだ?」

足を止めた。

「上流を探す方法を、考えています。黒板からは送信側に問い合わせができません。受け取る側の作りなので、逆には辿れないようです」

イレーネさんは羊皮紙を抱えていた。表情は動かなかった。

「シリアの方角は、確認しましたか」

「……はい」

「変わっていませんでした。沿岸部の方向です。本人は、近くなっている、と」

一拍、置いた。

「そちらに向かう理由が、ひとつ増えましたね」

それだけ言って、歩いていった。靴音が、廊下の奥へ抜けていった。

（……訊く順番が、逆だ）

僕は今日の午後、黒板とシリアの方角を初めて一本につないだ。その報告を、まだしていない。この人は、僕が上流の話をした次の一言で、シリアの方角を訊いた。

つないだ後の順番で、訊いてきた。

もう一つ、引っかかる言い方があった。ひとつ増えた、というのは、前から数えていたということだ。

（……一つ目を、僕はまだ聞いていない）

また、答えではなく場所を指された。前もそうだった。ただ、今度は、指し方に重さがあった。

---

夜、机に地図を広げた。

黒板は、面を起こしたまま脇に置いた。打つためではない。この部屋でいちばん明るいのが、それだった。

青白い光が、大陸の輪郭の上に落ちた。

中央に大聖核。そこから外へ向かって、線が細くなっていく。沿岸部。港がいくつか。その先は紙の色が変わって、海になる。

昼にシリアが指した向きを、地図の上に置いてみた。指の先は、中央から離れる方へ伸びていた。恩恵が薄くなっていく側だ。魔道具の動きが鈍り、やがて動かなくなる縁。

今日分かったことは、多くない。上流はこちらから名前を訊けない。訊けないのは隠されているからではなく、受け取る側にその口がないからだ。

それでも、届いているものには、送っている側がある。七十三年以上、届き続けているなら、七十三年以上、送り続けている場所がある。

場所がある、ということは、地図に載る、ということだった。

地下の束を思い出した。九枚。形式の記録と、数字の列と、二行だけの問い。

あの束のどこにも、方角は書いていなかった。

あの人は形式を辿った。辿って、003の手前で止まった。地図を広げた形跡はない。

（……あの人には、シリアがいなかった）

僕が先に進めるとしたら、そこだ。そこだけだ。

そこまで考えて、手が止まった。

先に進めるとしたら、という言い方は、この子を連れて行く、という話に、簡単に化ける。

（……訊くことと、連れて行くことは、違う）

違うと言い切れるかどうかは、今夜は決めなかった。決めるには、まだ何も分かっていない。

黒板を、伏せた。

部屋が暗くなった。地図の輪郭が消えて、窓の枠だけが残った。

窓を、開けた。

夜の風に、海の匂いはなかった。ここは、まだ中央だ。

（……では、シリアが指している先に、何がある）

---

用語解説

アップストリーム（upstream）：データや物が流れていく経路の、送り出している側を指す言葉。受け取る側はダウンストリーム（downstream）と呼ばれ、二つは川の上流・下流と同じ関係で対になる。運用の現場では「うちは下流だから、上流に確認してほしい」という言い方をよくする。下流に立っている限り、上流に何があるかは基本的に見えない。届いたものの形と、届く間隔と、その量からしか推し量れないためだ。テルが立てた「上から流しているのは誰か」という問いは、下流に立った者なら必ず一度は立てる問いであり、同時に、下流の道具だけでは答えの出ない問いでもある

逆引き（reverse lookup）：通常とは反対の向きに情報を辿る問い合わせのこと。名前から住所を引くのが順、住所から名前を引くのが逆にあたる。現実のネットワークではDNSの逆引きがこれで、IPアドレスからドメイン名を引く仕組みが用意されている。ここで大事なのは、逆引きは「そのための対応表があらかじめ作られている場合にだけ成立する」という点にある。用意されていなければ、どれだけ強い権限を持っていても引けない。断られ方が「権限が足りません」ではなく「その向きは定義にありません」になった時、それは扉が閉まっているのではなく、その方向に扉が作られていないことを意味する
