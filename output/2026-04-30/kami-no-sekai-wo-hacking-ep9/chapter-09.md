ep.9　第1章 第6話：七十三年前の接続 ―― 記録の壁の向こう側

廊下の石が冷えていた。
窓の外はもう完全に暗い。
イレーネが入っていった記録室の扉は、閉じたままだった。

（……もう一人）

その言葉だけが、頭の中で何度も折り返した。
接続形式だけじゃない。記録の残し方まで同じ。NODE-07以前から存在するものを引き継いでいる形式。
イレーネの言い方は、断定だった。仮説ではなく、すでに照合の済んだ事実として置かれていた。

足を動かした。
廊下の冷気が首筋に降りてくる。自分の靴音が、思っていたより遅く聞こえた。

部屋に戻った。
机の上にはまだ昨夜広げたままの羊皮紙。インクの瓶。読みかけの設定書。
椅子を引いて座った。座る前に、黒板を取り出していた。

黒板を膝の上に置いた。
指先が乾いている。深く息を吸って、コマンドを打った。

```
> trace --target=NODE-07 --history=before
```

返事を待った。

```
[ERROR: RECORD_BOUNDARY]
[no prior index accessible]
[最古層: NODE-07]
```

止まった。
角度を変えてみる。

```
> list --node=ARK/* --order=oldest
```

```
NODE-07: ACTIVE (応答なし)
NODE-06: SILENT
NODE-05: SILENT
NODE-04: SILENT
NODE-03: SILENT
NODE-02: SILENT
NODE-01: SILENT
[これより先のインデックスは存在しません]
```

「これより先のインデックスは存在しません」。
存在しない、ではない。**アクセス可能なインデックスとして**存在しない、という言い方だ。

（……削除されたか、別の管理下に置かれている）

前世で、似たメッセージを何度も見たことがある。ランサムウェア被害の初動調査で、ログを掘ろうとして、ある日付より前が綺麗に消えているケース。あの時、上司に呼ばれた会議室で、自分は短く言った。

——ログを消すのは、後ろめたいことがあるやつだけです。

笑われた。誰も信じなかった。
それでも、半年後に消えていた日付の意味が分かった時、誰も自分のところに「正しかった」とは言いに来なかった。

（……今は思い出さなくていい）

指を黒板に戻した。
もう一度、別の角度から。

```
> describe --target=NODE-07 --field=protocol_origin
```

```
プロトコル継承元: [非公開 / アクセス権限不足]
```

非公開。
ここまで来て、初めて「権限」という単語が返ってきた。今まで、テルの黒板は権限の壁を見せたことがほとんどなかった。神のシステムの内側にあるものは、たいてい読めた。

（……root権限で、読めないものがある）

それは、自分のroot権限よりも上の層に、別の何かがあるということだ。
あるいは、別の権限体系で書かれた領域に、NODE-07以前は属しているということだ。

（NODE-07の前に、何があったのか）

指が止まった。
頭の奥で、別の問いが組み上がっていく。

NODE-01から06は応答なし。NODE-07だけがZeroDayに使われている。そしてそのNODE-07の継承元は、NODE-07以前にある別の形式。
七十三年前の記録の「もう一人」は、その「以前の形式」で記録を残した。

(——前の形式を知っている人間が、七十三年前にいた)

(——その人間が使っていた接続を、今ZeroDayが部分的に引き継いでいる)

(——あるいは、引き継いでいるのは「もう一人」のほうではなく)

そこで指が止まった。

(自分と同じものを見られる人間が、七十三年前にもいた、ということになる)

口の中が乾いた。
喉の奥が、軽く詰まる感覚。前世でログの欠損に気づいた瞬間と、ほぼ同じ感覚だ。

ただ、答えは出ない。
出ない、ということが、たぶんいま唯一の手がかりだった。

黒板の文字が、ゆっくり消えていった。

翌朝、詰め所の一室に通された。

アルリックが扉の前に立っていた。腕は組んでいない。剣の柄に手をかけているわけでもない。ただ、立っていた。

短く言って、扉を開けた。

部屋は狭かった。窓は高い位置にひとつだけで、朝の光が斜めに落ちている。机を挟んで、椅子がふたつ。片方に、昨日の男が座っていた。

セルダ村の男だった。
あの倉庫で捕縛された、中年の男。

顔色は昨日より落ち着いていた。怪我はない。手にも縛りはない。机の上に、湯気の立つ碗がひとつ置かれていた。男はそれに手をつけていなかった。

「……座っていいですか」

声をかけた。
男が顔を上げた。咎める目でも、怯えた目でもなかった。

「どうぞ」

椅子を引いた。
アルリックは扉のすぐ内側で立ったままだった。腕も組まず、口も開かない。ただ、いる。

机の角を見た。
質問の準備はしていない。聞き出す立場でもない。昨日の倉庫で、すでに必要なことは分かっていた。

それでも、この男に会っておきたかった。
理由は、自分でもまだうまく言葉にできない。

「……昨日のことで、責めに来たわけじゃないんです」

男が小さく息を吐いた。

「分かっています。あの場で、騎士の方も『丁重に』と言いましたから」

その一言の言い方が、思っていたより穏やかだった。怒りでも、皮肉でもなかった。

「……ひとつだけ、聞きたくて」

「どうぞ」

男が碗の縁に指を置いた。湯気の角度がわずかに変わる。

「あの仕事を受けた時、迷いましたか」

男がしばらく黙った。
自分の指先を見て、それから天井の高い窓を見た。

「……迷いました。最初は」

「最初は、というと」

「村が焼けた後、しばらくは聖務局を待ちました。何度か、人を立てて助けを求めにも行きました。返事は来なかった。来た時には、もう冬で、村の井戸が凍って、誰の魔道具も動かなくなっていた」

声に怒りはなかった。
怒りで持っていく段階を、もう過ぎた声だった。

「ZeroDay、と呼ばれているんですね。私たちは、そう呼んでいません。ただ、向こうから来た人が、食事をくれた。最初は食事だけです。何かをしろとも言わなかった」

「……ええ」

「そのうち、荷を運んでくれと言われました。受けない理由は、もう、なかった」

男が碗を持ち上げた。
口を付けないまま、両手で持ち直した。

「悪いとは思っていません」

その言い方には、開き直りも、説得も、なかった。
「思っていません」という事実だけが、机の上に置かれた。

（……このひとは、悪人じゃない）

頭の中の言葉は、すぐに次に進もうとした。

——インフラが壊れていたんだ。神の恩恵が届かなかった。ユーザーは悪くない。インフラが壊れていたんだ。技術者が間に合わなかったんだ。

前世のサーバ障害で、何度も自分が言った言葉だった。ユーザーを責めるな。設計と運用の問題だ。
でも、その言葉を、いま、この男に向かって口にすることはできなかった。

口に出した瞬間に、それは「説明」になる。
この男に必要なのは、たぶん、説明ではない。

「……お話、聞かせてくれてありがとうございました」

それしか言えなかった。

男が、はじめて少し笑った。
笑った、というより、口の端がわずかに緩んだ程度だった。

「こちらこそ。聞きに来てくれた人は、あなたが初めてです」

机の上の碗からまだ湯気が立っていた。
扉のところで、アルリックが目を伏せたのが、視界の端に映った。

用語解説

レコードバウンダリ（RECORD_BOUNDARY）：本来は記録ログの「ここから先は読めない」という境界線のこと。古いログが意図的に削除されていたり、別の管理権限下に隔離されていたりすると、システムはこの境界に当たって応答を返す。この話でテルの黒板が「これより先のインデックスは存在しません」と返したのがこれにあたる。「無い」のではなく「読めない」という意味であり、削除や隠蔽の可能性を強く示唆する手がかりになる

プロトコル継承（protocol_origin）：本来は通信規格の世代をさかのぼり、現在の規格がどの古い規格を引き継いで作られたかを示す系譜のこと。新しいプロトコルは、たいてい古いプロトコルの仕様の一部を残している。この話でテルがNODE-07の継承元を読もうとして「アクセス権限不足」で弾かれたのがこれにあたり、NODE-07以前に別の形式が存在していたこと、そしてその形式が現在も別管理下にあることを意味している

権限不足（アクセス権限不足）：本来はシステムにログインしている利用者の権限が、要求した操作に対して足りないという意味。テルのroot権限はこれまでほぼあらゆる領域に通じていたが、この話で初めて「権限の上にさらに別の権限がある」という壁にぶつかった。神のシステムを外側から動かしているテルに対して、さらに上位の何かが存在していることを示す
