## シーン構成

### シーン1：午前 / テルの部屋 — 「届き方」の記録形式を考えながら新しいアプローチへ

**場所**: テルの部屋。机に羊皮紙と黒板。

**登場人物**: テルのみ。

**流れ**:
1. テルが「届き方を記録する」という指示を実行しようとしているが、記録の「形式」が決まらない。
   - 「何を、どの順で書けばいいのか」という問い。
   - ep13イレーネの「何が来ているかより、どう届いているか」という言葉が戻ってくる。
2. 昨夜の auth_container の返りを改めて読む。
   - 「照合形式: 自動 / トリガー: 接続時」という行を指でなぞる。
   - 「自動で照合されている。ということは——照合される側に、形式がある。合っているかどうかを確認するには、比べる基準が必要だ。基準は、向こうが持っている」
3. 論理の展開:
   - 「権限を照合している何かが外にある。それは、自分の権限の形式を知っている。知っているから照合できる。知っているということは、形式が届いている——でも自分はそれを見られない」
   - 「シリアに届いているものも、外から来ている。外から来ている点で、一致している」
   - F-07の小さな一歩: 「（……誰かが、自分のために外から権限を設定した。その誰かは、同じ外の側で、届けることもやっている。かもしれない。まだ、分からない。でも、同じ方向を向いている可能性はある）」
4. 新しいコマンドを試みる:
   ```
   > describe --target=NODE-07 --field=sync_protocol
   ```
   返り:
   ```
   [sync_protocol: 外部制御]
   [同期形式: 参照不可]
   [制御元: UNDEFINED]
   ```
   - 「外部制御」という新しいキーワード。「外部定義」「外部参照」「外部格納」に続く、四つ目の「外部」。
   - でも同期形式も制御元も、やはり参照不可。
   - F-07の進展: 「（……外から定義されて、外に格納されて、外で照合されて、外から制御されている。全部が外を向いている。向こうから届けているのも、同じ方向から来ているなら——）」
   - 「（……でも、それを確かめる手段が、まだない）」
5. F-01保温: 廊下の方から、アルリックか別の術士が「また不具合の間隔が縮まった、今日で三回目だ」という声が扉越しに聞こえる。テルが一拍置いて「N-01が動き始めている、と関係があるかもしれない」と内部で一行照合する。その先は追わない。

**感情の温度**: 焦りではない。「問いの方向が揃い始めた」という静かな集中。全部が外を向いている——それが「証拠なのか、それとも自分の見方のクセなのか」という自戒の一文も入れる。

### シーン2：昼前〜昼 / シリアの部屋 — 「届き方」をシリアと一緒に記録する試み

**場所**: シリアの部屋（本棟から渡り廊下を越えた先）。椅子に座っているシリア。
**登場人物**: テル、シリア。

**流れ**:
1. テルがシリアの部屋を訪ねる。「届いているものを、一緒に記録したい。中身じゃなくて、どう届いているかを」と告げる。
2. シリアの状態: 昨日より少し落ち着いた様子。壁に手を当てることなく椅子に座っている。顔色は戻っていないが、声は昨日より普通に出る。
3. テルが問いかける（Show形式で描写。直接の説明ではなく対話と反応で見せる）:
   - 「昨日より、どう?」→「……あります。ずっと。でも……なんか、慣れてきた気がします」
   - 「昨日、たまに大きくなる、って言ってたけど——波みたいな感じ?」→「……波、かな。うん。すごく短い。ちょっとだけ強くなって、すぐ戻る」
   - 「速さは?」→「……速い、です。わかんないけど。一定、じゃない気がする」
4. テルが黒板を出してpingを軽く打ちながら、シリアが「今、来た」と言うタイミングを記録しようとする。
   - テルの黒板側: 変化なし。「[応答あり / 信号微弱]」のまま。
   - シリア: 「……今」「……また」「……今、ちょっと大きかった」という断片的な報告。
   - テルが羽ペンで羊皮紙に「来た」のタイミングをメモする。変則的なパターンが見え始める。
5. テルが「来てるのって、一個のところから来てる感じ?」
   シリアが少し考える。「……なんか、違うと思う。混ざってる、みたいな」「……一個が一番大きくて。あとは、もうちょっと遠い感じ。二つか三つ」
6. N-01の進展: テルの内部思考。「（……複数のノードが届けている。そのうち一つが主導している。N-01の中で、動いているのは、この数だけなのか、それとも残りはまだ沈黙しているのか）」。
7. 届いているものの中身を引き出そうとする:
   - 「一番大きいのから、何か、分かることある?」
   - シリアが集中する顔になる。数秒、黙っている。
   - 「……わかんない。言葉、じゃないから。でも……なんか、急いでる感じ、がする。急いで送ってきてる、みたいな」
   - この一言が今章の感情の山場。
8. 新規-ep13-A（更新）: 「ことばじゃなくて、たくさん来る」という断片から、「急いでいる」という質が一つだけ加わった。中身は読めない。でも質の欠片が一つ見えた。
9. 靄の確認: 出ていない。シリアが疲れ始めた気配を感じて、テルが「もういい、ありがとう」と打ち切る。

**感情の温度**: ep13で「ちゃんと、見てるから」と言ったテル。今日もその延長線上にいる。記録する、ということが「見続けること」の具体的な形として機能している。シリアは「急いでいる感じ」という言葉を言い終えた後、何かを伝えられた安堵のような顔を一瞬見せる——テルはそれに気づくが、何も言わない。

### シーン3：午後〜夕方 / 廊下または記録室の前 — イレーネへの報告と次の問いの設定

**場所**: 廊下（定番の報告場所）。
**登場人物**: テル、イレーネ。

**流れ**:
1. テルがイレーネを捕まえて報告する。今日集まった「届き方」の記録を持っている。
2. 「複数のノードから届いています。二つか三つ。そのうち一つが特に強い。届き方は変則的で、一定ではありません。たまに強くなる。速さがある」
3. 「内容については——言葉ではない。でも『急いでいる感じがする』とシリアが言いました」
4. イレーネの反応:
   - 「急いでいる、というのは、シリア自身の感覚?」
   - 「シリアの言葉です。向こうが急いでいるのか、シリアがそう感じるのかは、分からないと」
   - イレーネが少し沈黙する。廊下の壁に目を向けた。「……そう」とだけ言う。
5. テルが「どう届いているかは、少し見えました。でも——届いているものを読む手段がありません。形式が分からない。形式を知らないと、読めない」
6. F-28の進展: イレーネが「七十三年前の複写に、まだ読んでいない部分が?」と問う。
   - テルが「複写は、あの四行だけです。F-41の通り、記録は複数の場所に分けて残されているとすれば——別の場所を探す必要がありますが、まだどこに何があるのかが」
   - イレーネが「もう一つ、方法がある。届いているものを、直接読めるようになるか。シリアを通じて、読む」
   - テルが「シリアに届いているものをリアルタイムで黒板に引き込む、ということですか」
   - イレーネが「できるかどうかは、あなたが判断して」と答えて歩き出す。
7. F-28の深化: テルの内部思考。「（……またこの人は、二択を差し出した。どちらが正解かを教えずに。七十三年前の別の記録を探す、か。シリアを経由して届いているものを直接読む、か。その二択の存在を、なぜこの人は知っているんだろう）」。「（調査で到達する答えじゃない。もっと近くにいる人間の出し方だ）」

**感情の温度**: テルが「訊けない」のではなく「訊いてもまだ出ない」という確信が強まる。イレーネに対する敬意とは別の、「この人の知っていることの外側には自分の問いが届かない」という感覚。

### シーン4：夜 / テルの部屋 — 新しい問いの設定と章末フック

**場所**: テルの部屋。机に灯り一つ。
**登場人物**: テルのみ。

**流れ**:
1. 夜。テルが今日の記録を整理している。「届き方」の記録と「読む手段がない」という壁が並んでいる。
2. イレーネの二択を頭の中で置き直す。「七十三年前の別の記録を探す」か「シリアを通じて直接読む」か。
3. 「直接読む」方向から考える:
   - 黒板はシリアに届いている信号を受け取れていない。受け取れない理由を問えないか。
   - コマンドを試みる:
     ```
     > describe --target=NODE-07 --field=relay_format
     ```
     返り:
     ```
     [relay_format: 参照範囲外]
     [対象: このノードは送信側ではありません]
     ```
   - 二行目で、手が止まる。
4. 新規-ep14-A: 「このノードは送信側ではありません」——これまでで初めて、「できない」ではなく「違う」という形の返りが来た。
   - 「（……NODE-07は、受信側だ。送っていない。受け取っている。送っているのは別にある）」
   - 「（だからシリアに届けているものの形式を、NODE-07に問うても、出ない。問う相手が、違った）」
   - 「（送信側を探す、ということが、次の問いになる）」
5. 新規-ep14-B: 「送信側を探す手段」という問いの設定。
   - 「送信側がどこにいるのかを知るには——受信側の記録を逆算するか、シリアが感知した方角をもとに探すか。後者はまだ準備ができていない。前者は、NODE-07の受信記録を見られるかどうかが問いになる」
6. 新規-ep11-A（保温）: 方角の話が内省に浮かぶ。「（シリアが二度、同じ方角を指した。心当たりは、ある。送信側がそこにいる可能性は高い。でも、今行っても黒板は使えない。まず、形式を知らなければ、行っても話せない）」
7. 章末フック:
   - 灯りが揺れた気がした。気のせいだった。
   - 「送信側は、別にある」という一行をもう一度、頭の中で置き直した。
   - 今まで、返りは「分からない」「参照不可」「UNDEFINED」の形をしていた。今夜の返りは違う形をしていた。「違う」という形。
   - 「（……この世界の黒板は、問いの形が正しい時、答えの代わりに「そこじゃない」と言う。そこじゃない、ということは——どこかに、正しい問い先がある）」
   - 灯りを消した。

## 感情の山場

**シーン2（シリアとの「届き方」記録の場面）**

「急いでいる感じ」という言葉。

言葉ではなく、感覚として届いているものの「質」の欠片が一つ出た。急いでいる。向こうが急いでいるのか、シリアが急いで受け取っているのか、まだ分からない。でも「急いでいる」という質があった、ということは、向こうには「何かを届けたい」という意図がある。意図のないものは、急がない。

これが今章のテルの静かな衝撃。「受信した量」ではなく「意図の気配」が初めて見えた瞬間。

## ライターへの執筆指示

### 文体・テンポ
- テルの内部思考: 全角「（……）」を使用（ep10・ep12・ep13の文体を最優先参照）
- 一文は短く。断定より推測・積み上げで。「〜かもしれない」「〜ということは」「〜とすれば」の積み重ね

- コマンドより内省の比重を上げる（コードブロックは1シーンに2ブロック以内）

- シリア: 文が短く途中で終わる。「なんか」「みたいな」「感じ」「わかんない」。「……」始まり多用。語彙が少ない。「急いでいる感じがする」という表現はシリアの語彙の限界での精一杯として描く
- イレーネ: 端的・断定的。「〜ね」「〜でしょう」「〜記録しておく」。感情表現なし。台詞ではなく動作で変化を示す（「廊下の壁に目を向けた」「少し沈黙する」等）
