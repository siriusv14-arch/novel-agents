ep.14　第1章 第11話：読む（リード）―― 届いているものは、形式を持っている

記録、というのは、難しい。

見たものを書くより、見方を決めるほうが、先にいる。

翌日の午前。机に、羊皮紙を一枚、広げた。昨夜の黒板の返りと、昨日のシリアの言葉を、書き出しておこうと思った。イレーネさんに言われたことを、やる。何が来ているか、より――どう届いているかを。

羽ペンを、持った。

それで、止まった。

（……どう届いているか、を、どう書けばいいんだ）

何を、どの順で書くのか。そこが、決まっていなかった。「来た」と書くのか、「何時何分に来た」と書くのか。「強かった」と書くのか、「どれくらい強かった」と書くのか。届き方を記録する、と言われて、頷いた。頷いてから、その届き方を、どういう項目で並べればいいのかが、分からないことに気づいた。

記録する前に、記録の形式を、決めなければいけなかった。

（……形式）

その言葉に、指が止まった。昨夜から、ずっと、同じ言葉の周りを回っている。

黒板を、開いた。昨夜の返りが、まだ残っていた。

```
[auth_container: 外部参照]
[格納先: NODE-07外部 / アドレス: 参照不可]
[照合形式: 自動 / トリガー: 接続時]
```

三行目を、指でなぞった。

照合形式、自動。トリガー、接続時。

（……照合されている、ということは）

照合する、というのは、比べることだ。何かと、何かを、突き合わせて、合っているかを見る。僕が黒板に触れるたびに、外に置かれた僕の権限が、自動で照らし合わされている。合っているかどうかを、確かめられている。

合っているかどうかを確かめるには、比べる相手が要る。基準が要る。

（……基準は、向こうが、持っている）

僕の権限の「正しい形」を、向こうが知っている。知っているから、照らし合わせられる。触れるたびに、僕の形式を、向こうが読んでいる。読めているのは、向こうだ。僕ではない。

僕の権限の形式は、僕には見えない。参照不可。でも、向こうには見えている。向こうは、僕の形式を知っている。知っているから、僕が接続するたびに、その形式が、確かに届いている。向こうへ。

（……形式が、届いている）

指が、止まった。

昨日、シリアが言った。ことばじゃないのに、たくさん来る。中身は読めない。でも、量として、届いている。

僕の権限も、同じだった。中身は僕には読めない。でも、形式として、向こうへ届いている。届いていなければ、照合できない。

方向は、逆だ。片方は、向こうから僕たちの側へ。片方は、僕の側から向こうへ。でも、どちらも、外から来ているものと、外へ行っているものだ。外に置かれ、外で照合され、外から届けられている。

（……全部が、外を向いている）

外部定義。外部格納。外部参照。自動照合。ep12から、ずっと、同じ方を向いた言葉ばかりが、返ってきている。僕の権限を外に置いた誰かと、シリアに何かを届けている誰かが、もし同じ側にいるとしたら――。

線が、引きたくなった。

引きかけて、止めた。昨夜と、同じだ。まだ、引きたいから引く線だ。

（……でも）

昨夜より、少しだけ、違うことがあった。昨夜は、二つの外――僕の権限の「外」と、七十三年前の記録の「外」――が、似ている、というだけだった。今朝は、そこに、三つ目の「外」が並んだ。シリアに届いているものの「外」。

三つが、同じ方を向いている。

それを、証拠と呼んでいいのか。それとも、僕が、外という言葉を三度聞いたせいで、全部を同じ方向に見たがっているだけなのか。壁の模様を、人の顔だと思い込むように。

（……分からない。でも、確かめる、一歩があるとしたら）

黒板の側から、もう一つ、訊けることがあった。届き方の記録を始める前に、システムに、「届き方そのもの」を訊いてみる。同期の、形式を。

指を、コンソールに当てた。

```
> describe --target=NODE-07 --field=sync_protocol
```

返ってきた。

```
[sync_protocol: 外部制御]
[同期形式: 参照不可]
[制御元: UNDEFINED]
```

一行目を、読んだ。

外部制御。

（……また、外だ）

外部定義。外部格納。外部参照。そして、外部制御。四つ目の「外」だった。同期の形式も、外で制御されている。どういう間隔で、どういう順で、何を送り、何を受けるか。それを決めているのは、NODE-07ではない。外の、誰かだ。

でも、二行目も、三行目も、いつもの形だった。同期形式、参照不可。制御元、UNDEFINED。制御している何かは、ある。でも、それが何かは、訊けない。訊く宛先が、登録されていない。

（……外から定義されて、外に格納されて、外で照合されて、外から制御されている）

全部が、外を向いている。全部が、同じ方向を指している。もし、向こうから届けているのも、同じ方向から来ているなら――届けている側と、僕の権限を制御している側が、同じ側にいるなら――。

その先に、指を伸ばした。

伸ばして、届かなかった。

（……でも、それを確かめる手段が、まだ、ない）

制御元は、UNDEFINED。同じ側かどうかを訊こうとしても、訊く相手が、いない。方向が揃っている、というところまでは見えた。揃っている方向の、その先に何がいるのかは、見えない。

チョークを、置いた。

焦りでは、なかった。むしろ、静かだった。問いの向きが、揃い始めている。ばらばらだった問いが、少しずつ、同じ方角を向いてきている。それが、答えに近づいているのか、それとも、僕が同じ方角を向かせているだけなのかは、まだ、分からないままで。

その時、扉の外を、誰かが通った。

足音が、二つ。廊下の方で、止まった。話している。片方は、アルリックの声に、似ていた。防衛の術士だ。

「――また、間隔が縮まってる。今日で、三回目だ」

「今日で?」

「昨日は、二回。一昨日は、一回。増えてる。不具合の、出る間隔が、また短くなってる」

足音が、遠ざかった。

（……不具合の、間隔が、縮まっている）

しばらく、静かだったものが、また、動き始めている。

その言葉を、机の上の羊皮紙に、書き足そうかと思って、羽ペンを持ち上げた。持ち上げて、止めた。書くには、まだ、線が細い。

でも、頭の中で、一行だけ、照らし合わせた。不具合の間隔が縮まっている。シリアへの接触が、切れ目なく続いている。NODE-01が――応答なしだった、あの六つの、少なくとも幾つかが――動き始めている。この三つは、別々のことなのか。

（……関係が、あるかもしれない）

そこまでで、止めた。その先は、まだ、追わない。追う前に、確かめておくべきことが、別にあった。

シリアの様子を、まだ、見ていなかった。

羽ペンを置いて、黒板を懐にしまった。羊皮紙は、白いまま、机に残った。届き方の記録は、一行も、書けていなかった。

書けていないのは、たぶん、まだ、届き方を、見ていないからだった。

部屋を、出た。

「……ううん」

膝の上で、黒板の縁を、指で押さえた。波。短い。一定ではない。羊皮紙は持ってこなかったけれど、言葉が、頭の中に、一つずつ、置かれていく。

「速さは、どう。速い?　ゆっくり?」

膝の黒板に、指を当てた。深く入れず、入り口だけ、軽く触れる。

「今から、僕、こっちを、ちょっと触るから。シリアは、来た時に、教えて。今、来た、って。大きさも、分かったら」

「……はい」

「シリア」

訊いた。

一個が、いちばん大きい。あとは、遠い。二つか、三つ。

（……複数の、ところから、届いている）

膝の上で、指が、止まった。

会議で、僕は言った。応答なしの六つは、沈黙していたんじゃない。フォーマットが合っていないだけだ、と。あの六つの中の、二つか、三つが、動いている。シリアが感じているのは、その数だ。残りは――残りは、まだ、沈黙しているのか。それとも、シリアの届く範囲の、外にいるのか。

（……急いでいる）

昨日まで、届いているものは、量だった。ことばじゃないのに、たくさん来る。切れ目がない。多い。それは、大きさの話だった。どれくらい来ているか、の話だった。

今、シリアが言ったのは、大きさではなかった。

急いでいる。速さでも、なかった。速い、はさっき、別に言った。急いでいる、は、速さとは違う。速さは、届き方だ。急いでいる、は――届けている側の、様子だ。

（……向こうが、急いでいる）

急ぐ、というのは、間に合わせたいものが、あるということだ。届けたい、期限がある。何かを、急いで、送りたい。急ぐものには、意図が、ある。意図のないものは、急がない。

昨日まで、シリアに届いていたのは、「量」だった。今日、そこに、「質」が、一つだけ、加わった。急いでいる、という質が。

それが、シリアの感覚なのか、向こうの様子なのかは、まだ、分からない。シリアが、切れ目なく受け取り続けて、受け取る方が急いている、ということも、あり得る。でも――シリアは、慣れてきた、と言った。びっくりしなくなった、と。慣れてきた側が、急ぐだろうか。

分からない。分からないけれど、届いているものの、いちばん奥に、初めて、「急いでいる」という、意図の、気配みたいなものが、見えた。

量ではない。速さでもない。届けたい、という、向こうの、意志の、欠片。

そのことに、静かに、打たれていた。

シリアが、こちらを見ていた。

僕は、それに気づいた。

「シリアに、届いているものを」

言葉を、確かめた。

「リアルタイムで、黒板に、引き込む――ということですか」

「できるかどうかは、あなたが、判断して」

イレーネさんが、歩き出した。

背筋を伸ばした、いつもの歩き方で、赤い光の中へ、入っていく。問い返す間は、なかった。いつも、そうだった。

一人で、廊下に、残された。

（……また、この人は、二択を、差し出した）

一つ。七十三年前の、別の記録を、探す。一つ。シリアを経由して、届いているものを、直接、読む。二つの道を、並べて、置いた。どちらが正しいかは、言わずに。

（……なぜ、この人は、その二択の、存在を、知っているんだろう）

考えたのは、答えではなく、道の方だった。僕が、どこで詰まって、次に何を選ばなければいけないか。その、選択肢の形そのものを、イレーネさんは、僕より先に、持っていた。届いているものを読む手段が二つある、ということを、僕がそこに困り着く前に、知っていた。

これは、調査で、到達する答えではなかった。古い記録を読み解いてきた人が、案内する、という手つきでは、なかった。もっと、近い。何かを、直接、知っている人間の、出し方だった。

訊けば、答えるだろうか。

答えない気がした。昨日と、同じだった。訊いてはいけない、という遠慮では、ない。訊いても、まだ、返ってこない段階だ、という確信に、近かった。この人の知っていることの、外側には、僕の問いは、まだ、届かない。

だから、訊かなかった。

赤い光の消えた廊下を、部屋の方へ、歩き出した。

夜、机に、灯りを一つ、点けた。

黒板を、置いた。昼のうちの記録は、頭の中で、整理し終えていた。二つのものが、並んでいる。届き方の記録と、それを読む手段がない、という壁。届き方は、少し、見えた。でも、届いているものは、読めない。

イレーネさんの、二択を、頭の中に、置き直した。

七十三年前の、別の記録を、探す。当てが、ない。今は、動かせない。

シリアを通じて、直接、読む。

こちらから、考えることにした。

シリアには、届いている。切れ目なく、変則的に、複数のところから。でも、僕の黒板には、来ていない。信号微弱のまま。同じ通信網なのに、僕の窓は、閉じている。シリアの窓は、開いている。

（……なぜ、僕の側には、届かないんだ）

その理由を、訊けないか。黒板が、シリアに届いている信号を、受け取れない。受け取れない、その理由を、システムに、問う。中継の、形式を。

指を、コンソールに、当てた。

```
> describe --target=NODE-07 --field=relay_format
```

返ってきた。

```
[relay_format: 参照範囲外]
[対象: このノードは送信側ではありません]
```

一行目は、いつもの形だった。参照範囲外。訊けない壁の、慣れた形。

二行目で、手が、止まった。

このノードは、送信側では、ありません。

（……送信側では、ない）

読み返した。もう一度、読んだ。

これまで、返ってきたものは、いつも、同じ形をしていた。参照不可。参照範囲外。未登録。UNDEFINED。訊いても、答えがない。壁がある。窓が塞がっている。「分からない」「できない」の形を、していた。

今夜のは、違った。

「できない」ではなかった。「違う」だった。

このノードは、送信側では、ありません。訊く相手が、間違っている、という返り。壁がある、のではなく、そもそも、ここには、それがない。ここは、それをする場所ではない、という。

（……NODE-07は、受信側だ）

灯りが、揺れた気がした。気のせいだった。

NODE-07は、送っていない。受け取っている。シリアに届いているものの、中継の形式を、NODE-07に問うても、出ない。NODE-07自身が、送っていないからだ。送っていないものの、送り方を、訊いても、答えられない。

問う相手が、違った。

（……送っているのは、別に、ある）

そこまで、辿って、指が、止まった。

これまで、ずっと、NODE-07を、問い続けてきた。NODE-07の権限、NODE-07の形式、NODE-07の同期。全部、NODE-07に、訊いてきた。NODE-07が、いちばん近い窓だったからだ。でも、NODE-07は、受信側だった。届けている、送信側は、別に、ある。

（……送信側を、探す。それが、次の、問いになる）

どこにいるのかを、知るには。

二つ、あった。一つ。受信側の、記録を、逆算する。NODE-07が、何を、どこから受け取ったか。その受信の記録を、見られれば、送ってきた側が、辿れるかもしれない。一つ。シリアが、感じた、方角。二度、同じ方を、指した。あの方向に、送信側が、いる可能性は、高い。

後者は、まだ、準備が、できていない。

（……シリアが、二度、同じ方角を、指した）

沿岸部の、先。恩恵の薄れる縁。心当たりは、ある。送信側が、そこにいる可能性は、高い。でも、今、行っても、黒板は、使えない。恩恵の届かない場所では、僕の道具は、動かない。丸腰で、辿り着いても、話せない。

（……まず、形式を、知らなければ、行っても、話せない）

だから、逆算の方から、始めるしかなかった。NODE-07の、受信記録を、見られるかどうか。それが、次の、問いになる。今夜は、そこまで、辿り着けた。手段は、まだ、ないけれど、問いの、形が、決まった。

チョークを、置いた。

灯りが、また、揺れた気がした。今度も、気のせいだった。部屋が静かで、自分が、その静けさに、気づいた、というだけだ。

「送信側は、別に、ある」

その一行を、もう一度、頭の中で、置き直した。

今まで、返りは、いつも、「分からない」「参照不可」「UNDEFINED」の形を、していた。訊いても、空白が、返ってきた。答えが無いのではなく、答えを訊く相手すら、定義されていない。そういう、返りだった。

今夜の返りは、違う形を、していた。

「違う」という形。ここではない、という形。それは、空白では、なかった。空白には、方向がない。でも、「ここではない」には、方向が、ある。ここではない、なら、どこか、別のところが、ある、ということだ。

（……この世界の黒板は）

指を、閉じた黒板の縁に、置いた。

（……問いの形が、正しい時、答えの代わりに、「そこじゃない」と、言う）

そこじゃない、ということは。

（……どこかに、正しい、問い先が、ある）

問いの形が、まだ、出来ていないだけだ。出来ていないから、まだ、そこに、届かない。でも、なかった、で、終わったことは、一度も、ない。今夜も、そうだった。無い、ではなく、違う、が、返ってきた。違う、は、ある、の、裏側だ。

黒板を、閉じた。

灯りを、消した。

用語解説

sync_protocol（同期プロトコル）：本来は、二つ以上のシステムが、互いの状態を「揃える」ためにやり取りする、約束事のこと。どういう間隔で、どういう順で、何を送り、何を受け取るか――そのタイミングと手順を、あらかじめ取り決めておく。これが揃っていないと、片方が送っているのに、もう片方が受け取れない、ということが起きる。逆に言えば、片方だけに切れ目なく届いている、という状態は、その同期の形式が、どこかで、片方に合わせて決められている、という意味になる。この話でテルが sync_protocol を問うと、「外部制御」と返った。同期のやり方が、NODE-07の内側ではなく、外の何かによって決められている、ということだ。外部定義、外部格納、外部参照に続く、四つ目の「外」であり、届き方そのものが、向こうの側で握られている、という気配が、ここで一つ、重なる

relay_format（中継形式）：本来は、ある信号を、別の場所へ「取り次いで送る」ときの、その取り次ぎ方の形式のこと。中継とは、自分が発信源ではなく、どこかから来たものを、別のどこかへ渡す働きをいう。中継の形式を問うということは、「あなたは、何を、どこから受けて、どこへ渡しているのか」を訊く、ということだ。だから、この問いが成立するのは、相手が「中継している」ことが前提になる。この話でテルが relay_format を問うと、「参照範囲外」に続けて、「このノードは送信側ではありません」と返った。中継の形式を訊いたはずが、返ってきたのは、そもそもの前提のずれの指摘だった。NODE-07は、送っていない。受け取っている側だ。届けている送信側は、別にある――問いの相手が、違っていた、という返りである

「このノードは送信側ではありません」（エラー形式の意味）：これまでテルの黒板が返してきたエラーは、たいてい「参照不可」「参照範囲外」「UNDEFINED」といった形をしていた。訊いても答えがない、訊く宛先すら定義されていない――いわば「空白」が返ってくる、拒絶の形だった。だが、この返りは、それらとは種類が違う。「できない」でも「無い」でもなく、「違う」と言っている。あなたの問いは、この相手に対しては、成立しない。ここは、その答えを持っている場所ではない――という、いわば問い先の訂正である。プログラムの世界では、こうした返りは時に、拒絶よりも多くを教える。空白には方向がないが、「ここではない」には方向がある。ここではない、ということは、どこかに、正しい問い先がある、ということだからだ。答えの代わりに、答えのある方角が、ひとつ、指し示されている
