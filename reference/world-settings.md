## 2. 世界観設定

### 魔法の本質
神が世界を制御するために構築した「世界制御システム」そのもの。

| 世界の概念 | ITの概念 |
|-----------|---------|
| 魔法陣 | ソースコード（例：神記創世基本核 v1.0.4） |
| 詠唱 | 実行コマンド |
| 術式構造 | プログラムロジック |

### 神の設計ミス
創造主である神は「機能の実装」と「拡張性」を優先し、**「セキュリティ」という概念を完全に無視**した。システムは複雑に絡み合い、無意味なループ処理や魔力の漏れ（メモリリーク）が放置されている。

### 神が人類に制限をかけた理由（真相）
- 人類はかつて際限なく戦争を繰り返す乱暴な種族だった
- 神は人類の自滅を防ぐため、肉体に意図的な制限をかけた
- 制限の代償として、信仰力によるインフラ（魔法・術式）を与えた
- つまり神のシステムは「**管理**」と「**恩恵**」がセットになっている

| 制限の内容 | 恩恵の内容 |
|-----------|-----------|
| 身体能力の上限を抑制 | 回復魔法・医療術式 |
| 攻撃衝動の緩和 | 暖房・水道・灯火インフラ |
| 戦闘本能の抑制 | 農業・建築の補助術式 |
| 寿命の管理 | 信仰力による生活の安定 |

### 人体のアーキテクチャ
人体は神のシステムの末端ノード（IoT機器）として設計されており、信仰力通信網に常時接続することで回復魔法・生活インフラの恩恵を受ける。この「接続される存在」という設計が、感染の入り口にもなっている。

| 世界の概念 | ITの概念 |
|-----------|---------|
| 人体 | IoTデバイス（末端ノード） |
| 魂 | デバイスID |
| 信仰力通信網 | 神のサーバーとの常時接続 |
| 感染 | デバイスへのマルウェア侵入 |

### この真相がもたらす構図

| 立場 | 解釈 |
|------|------|
| 神 | 人類を守るために制限した。悪意はないが同意を取っていない |
| ZeroDay | 制限は支配である。解放すべき |
| テル（現時点では未認識） | 修復すること＝制限の維持と気づいた時が最大の葛藤 |

## 3. 世界地理設定

### 基本構造
大陸が一つ。正教会が大部分を支配している。大陸の中央部から沿岸部に向かうほど、神のシステムの恩恵が薄れる。海を渡った先に島々が点在しており、神の恩恵がほぼ届かない。

### 地域別の恩恵レベル

| 地域 | 神の恩恵 | 住民の状況 |
|------|---------|-----------|
| 大陸中央部（聖都アルカナム周辺） | 最大 | 魔道具・医療・インフラが充実 |
| 大陸内陸部 | 中程度 | 基本インフラはあるが不安定 |
| 大陸沿岸部 | 弱い | 魔道具が動かない地域もある |
| 海上 | ほぼなし | 神の術式が海水で減衰する |
| 島嶼部 | 皆無 | 神のシステムが届かない完全な空白地帯 |

### ZeroDay陣営の拠点
- 大陸沿岸部の廃港町を複数の中継拠点として使用
- 主要拠点は島嶼部のいずれかの島（神のシステムが届かないためテルの黒板が使えない）
- 島嶼部こそが「神の恩恵なしで生きる人々」が実際に暮らす場所であり、ZeroDayの思想の原点

### 大聖核の位置
- 大陸中央部、聖都アルカナムの地下深部
- 大陸全土の信仰力ネットワークの中枢
- 物理的な要塞と術式による多重防衛が施されている
- ZeroDayの最終目標であり、テルが守り抜かなければならない場所

### WW2型進行との対応

| WW2のイメージ | 本作での対応 |
|-------------|-----------|
| 欧州各地の局地戦 | 大陸各地の中継塔・拠点をめぐる攻防 |
| 太平洋の島嶼戦 | 沿岸部から島嶼部への進出をめぐる戦い |
| 敵本国への進攻 | ZeroDayの主要拠点がある島への上陸作戦 |
| 最終決戦 | ZeroDayとテルの直接対面 |

## 5. 感染・覚醒設定

| 呼称 | 陣営 |
|------|------|
| **感染** | テル陣営（正教会・聖務局） |
| **覚醒** | ZeroDay陣営（Qyren） |

> ZeroDayのほとんどの陣営員は覚醒者である

### メリット（ZeroDay陣営が「覚醒」と呼ぶ理由）

**① 身体能力の強化**
- 神のシステムが人体にかけていた制限が外れる
- 疲労回復が早く、筋力・持久力が常人を超える
- 傷の治りが早いが、神の回復魔法は効かなくなる

**② 真実へのアクセス**
- 神のシステムが意図的に隠蔽・書き換えた情報が見えるようになる
- 神のシステムが恩恵を与えていない地域や人々の実態
- 正教会が民衆に見せていない歴史的事実

### デメリット（テル陣営が「感染」と呼ぶ理由）
- 神のシステムの恩恵が一切受けられなくなる
- 魔法による治療・暖房・水道など生活インフラが使えない
- 感染の痕跡が残り、再覚醒のリスクが常にある
- 強い感情や疲労で、意図せず周囲の術式を乱すことがある

### 感染メカニズムの構造
感染は「コンピューターウイルス的な情報汚染」と「生物学的な病原感染」のハイブリッドである。ZeroDayの感染コードが信仰力通信網（神のシステム）経由で人体ノードに侵入し、**データレイヤー**（魂・術式回路）と**肉体レイヤー**（靄・体調不良・身体症状）の両方で同時に進行する。デジタルとバイオが融合したこの世界特有の仕組みであり、片方だけを除去しても完全な回復には至らない。

### ZeroDayの矛盾
- 覚醒者はZeroDayの解放技術がなければ生きていけない状態になる
- ZeroDayはこの矛盾を認識しており、**技術の民主化**で解決しようとしている
- 最終的にZeroDay自身も不要になる状態を目標としている

### 物語上の葛藤ポイント
- テルが感染を除去することは、相手から「**力と真実を奪う行為**」でもある
- 覚醒者の中には除去を拒否する者が出てくる
- 「感染を除去することは本当に正しいのか」というテルの内面的葛藤につながる

## 7. 聖務局の内規

### 正式な教義
神のシステムへの改変は重大な異端行為。「神のシステムは不可侵」が正教会の公式見解。

### 聖務局内の慣例
- 緊急時に限り、システムへの最小限の介入は黙認される
- ただし「改変」ではなく「**修復**」という名目で処理される
- 記録には「術式の正常化」と書かれ、改変の事実は残らない
- この慣例を知っているのは聖務局の上層部のみ

### テルへの影響
テルは正式にこの慣例を説明されていない。この曖昧な立場が後にF-02の回収時に問題として浮上する。

## 8. これまでのストーリー進行

### ep.1（第0章第1話）「再起動（リブート）―― 転生と、最初のバグ発見」
前世（桜井輝明）がランサムウェア被害の復旧デスマーチの末に過労死。異世界の孤児院に赤ん坊として転生。魔法陣がスパゲッティコードに見えることに気づき、最適化に成功する。

### ep.2（第0章第2話）「リファクタリング・ライフ ―― 信仰という名のライセンス認証」
転生15年後。孤児院の水流魔道具のスタックオーバーフローを修復。黒板（物理コンソール）を使ってroot権限でシステムに介入できることを確認。世界の根幹プログラムを直接操作できる危うさと責任を自覚する。

## 11. 執筆ガイドライン

### 描写の基本方針
- 「**誰が・どこで・どんな表情・動作で**」を各シーンに必ず入れる
- 過剰な修飾語は使わない。一文で情景が見えるレベルに留める
- あとがきは記載しない

### テルのキャラクター描写
- 前世のトラウマを色濃く描く。感情的な場面を丁寧に入れる
- 前世で果たせなかったことを今世で達成することで少しずつ自信を取り戻す描写を入れる

### テンポと信頼関係
- テルはまだ新入りの下っ端。展開を急がない
- 仲間との信頼関係はゼロから。物語の進行によって信頼関係を築き地位を得ていく

### 戦闘シーンの構造

| レイヤー | 内容 | 描写スタイル |
|---------|------|------------|
| サイバー空間 | テル vs ZeroDayのコマンド攻防 | ターミナル表示＋内部思考 |
| 物理空間 | 傭兵 vs 騎士団 | 剣戟・魔法戦・肉弾戦 |
| 連動演出 | 両者が同時進行し影響し合う | コードが変わる→術式が暴走→騎士が吹き飛ぶ |

### ZeroDay陣営の描写
- 単純な悪役として描かない
- 貧困・差別・疎外といった背景を持つ人間として描く
- スチームパンクの美学として描く。「汚い・粗野」にしない

### ヒロインとの関係
- 3人のヒロインとの関係を話の進行とともに自然に縮めていく
- 最終的には恋に落ちるような話も入れる
- ただし恋愛小説ではないので過度な描写は控える

### 用語解説フォーマット
各話の最後に、作中に登場したIT用語を以下の形式で解説する。
> 「実際のIT用語はこうだが、この話ではこう使われている」
> 作中に登場していない言葉は解説に含めない
