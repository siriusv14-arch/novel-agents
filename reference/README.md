# reference/ フォルダへの資料の置き方

このフォルダに既存の小説本文・世界設定・キャラクター資料を配置することで、AIチームが内容を読み込み、一貫性を保ちながら続きを執筆します。

---

## ファイル命名規則

ファイル名の**プレフィックス（先頭の語）**でAIが役割を判別します。必ずルールに従って命名してください。

| プレフィックス | 内容 | 例 |
|---|---|---|
| `novel-` | 小説本文 | `novel-01.md`, `novel-02.md`, `novel-prologue.md` |
| `world-` | 世界設定 | `world-geography.md`, `world-magic.md`, `world-history.md` |
| `characters-` | キャラクタープロファイル | `characters-main.md`, `characters-sub.md` |
| `plot-` | プロット・あらすじメモ | `plot-outline.md`, `plot-future.md` |
| `style-` | 文体・執筆方針 | `style-guide.md` |

---

## ファイルの書き方テンプレート

```markdown

本文をそのままここに貼り付けてください。
AIはこのファイルから文体・テンポ・語り口を学びます。
```

## AIの読み込み順序

AIは以下の順序でファイルを読み込みます:

1. `novel-*` — 物語の現在地と文体を把握
2. `world-*` — 世界観・用語・設定を把握
3. `characters-*` — キャラクターの個性・関係性を把握
4. `plot-*` — 今後の方向性を確認
5. `style-*` — 文体の好みを確認

---

## 注意事項

- ファイルはMarkdown形式（.md）で保存してください
- 文字コードはUTF-8を推奨します
- reference/ 配下のファイルはGitで管理されます。公開したくない内容は含めないよう注意してください
